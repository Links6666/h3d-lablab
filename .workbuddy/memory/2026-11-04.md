## 阶段目录名收敛到登记表（ADR-0018 D5，提交 7ac2d26，已推送）

### 病根：两份手写清单漂向**相反**方向
| 副本 | 缺什么 |
|---|---|
| `paths._STAGE_CHILDREN`（迁移） | `10_clean` / `20_registered` / `60_qc` |
| `cli._cmd_init`（初始化） | `10_dense` / `00_ref` |

一份多一份少，谁都不完整。所以昨天那三个目录留在根目录不是"忘了加"，
是**结构上必然**。

### 改法
`STAGE_DIRS = {逻辑名: 目录名}` 唯一真源；`_STAGE_CHILDREN` 与 `h3d init`
都从它派生。三条守卫（`tests/test_stage_dirs_single_source.py`）：
1. 登记表每个目录必须在迁移清单里
2. 迁移清单不许有登记表以外的目录
3. **源码里的 `\d\d_[a-z]+` 字面量必须都已登记**

### 第 3 条当场抓到真遗漏：`00_ref`
两期对比（X1/X4）的**参考期几何**目录，用户手工放置。原来不在任何清单里 →
迁移会把参考期数据留在项目根 → X1 报「缺参考期 00_ref/<件>/*.ply」SKIPPED。
**数据没丢，但用不上**。这就是守卫测试的价值，不是形式主义。

真机：`h3d init` 12 → 14 个目录；`D:/h3d_relic_test` 核验仍 PASS 23。

### 没做的事（判断项）
147 处调用点仍用字面量（`os.path.join(task.root, "10_clean", …)`）。全量换成
`paths.STAGE_DIRS["clean"]` 要动 40 个文件，收益只是"更好看"；**守卫已经拦住
漂移**，那才是要防的。不做。

### 推送到 502 → openssl 后端成功
`git push` 报 `CONNECT tunnel failed, response 502`；`-c http.sslBackend=openssl`
一次就过（和昨天同样的症状与解法）。

## 真打一次包，抓到三个只在打包版出现的缺陷（ADR-0019，提交 f2471b3）

加了 GUI 核验按钮后按惯例真打包（PyInstaller 3m17s、238MB onefile）。三条手写
清单里任何一条没跟上，表现都是「点了没反应」或「跑到某阶段才崩」，**源码运行时

**无参启动 GUI**，用户以为什么都没发生。→ 从 `h3d.cli._build_parser()` 派生。

## r24：数据来源声明 + 采样定种子（提交 317251d / 8003eca，已推送）

### 起点是一个开关，落点是「数字不可复现」
给约束面板加「数据来源」下拉（`runner.data_source`：auto / laser /
photogrammetry）。做 auto↔laser 对照实验时发现两个**等价**分支算出的中误差
不同：86.7811 / 87.4155 / 87.0148，同一份数据三次运行。

根因：`mesh.sample_points_uniformly(n)` **没有 seed 参数**（Open3D 0.19 实测），
用进程级随机源。同一坑 2026-11-03 在**对齐精化**踩过（`_REFINE_SEED`），
当时只修了那一条路径 —— M5 这条因为「差异 <1%」被漏掉。
**小于 1% 的漂移最危险**：小到不触发断言，又大到让两天前的表对不上。

修法不是「在 M5 里也调种子」，而是收敛入口：
`h3d.io.sample_surface(mesh, n, seed)` 把「定种子 + 采样」绑死，没法只做一半。
接上 5 处：surface_coverage / qc_rmse_units / X1 的 mesh→点云 /
hausdorff_distance / `geo_align._seed_random`（改为委托）。
修后 auto 与 laser 逐字相同（87.4019），跨进程重跑也相同。

### 判据：证据压过声明（硬红线）
`resolve_metric_units(declared, has_raw, dense_source)` → `(units, reason, conflict)`。
- `photogrammetry` → 恒 False（与 00_raw 有没有文件无关）；
- `laser` → 要「真有 raw」+「M1 没判成 raw_looks_like_sfm」两条同时成立；
- 不成立 → False + WARN + `declared_source_conflict`。
**声明是把判断权交回用户，不是绕过诚实性检查的后门**：能压过证据的话，
勾一下就能把自证数据包装成米制结果，比没有这个功能更糟。

`metric_units_reason` 同时落 manifest 与 `qc_metrics.json`：只落布尔的话，
auto（机器猜）与 photogrammetry（人声明）事后长得一模一样，而两者可信度差一个
量级。判门失败时 manifest 不写，qc_metrics.json 是唯一留档。
