# B2/X3 单期异常检测 与 X4 时序追踪：细节与判据

> 从 `MEMORY.md` 拆出。`MEMORY.md` 只留一句话结论，动这两块前先读这里。
> 设计与失败过程见 `docs/adr/0003-single-epoch-anomaly.md`、`0004-temporal-tracking.md`。

## X3 检测核心

- **背景必须是局部中位数**（`cv2.medianBlur`，8 位量化 O(1)/纹素，核 201 仅 99 ms；**上限 255**）。
  均值/裁剪均值都失效（病变占窗 16% 即把正常残差抬到 0.16ΔE → 外糊一圈、内部 z=2.79 漏检）。
- **逐像素二分求局部中位数不成立**：每像素各带阈值而窗口计数须同一阈值 → 计数恒 0.538 不动、
  背景为 ∓amp、全图 z 归零。
- 尺度**不用中位数**（双峰残差落到 0 → 每条纹一半误报）；换按岛后不再用块级分位数。
- 多尺度（31/81/201）与颜色/纹理两路都**取最大不取平均**（平均被稀释：10.9→2.96）。
- **纹理用结构张量不用 LBP**（popcount 丢方向；一致性 1.00 vs 0.10）。三闸门：当前有结构 +
  基线有健康证据 + 基线本身一致。
- **方向基线要排除可疑区**（否则两侧都判「方向变了」，外糊 100 texel、IoU 0.61）；纹理证据
  只在颜色没响应处补位。
- **注入方法会骗人**：`255-pixel` 在中间调 ΔE 只有 14 → 用「L 推离中间调 + a/b 取反」并打印 ΔE。
- 真机注入（ΔE=120）：24/40 texel 全覆盖、增量 IoU ≥0.87；80 texel 2/3。**增量 IoU**（扣掉既有
  报警）才是边界精度。
- **80 texel 漏检是 σ 不是信号**（`scripts/verify_x3_bigpatch.py`：三处残差都 97~113，σ_L
  30.3/53.2/15.7 → z 3.21/1.82/6.37）。低信噪比不是估计器缺陷，别用「按面积累加证据」硬拉
  （σ=53 的根源就是材质交界）。改为报下限 `anomaly_sigma_median`（**只取 L 通道**，取错恒为
  地板 2.0）。

## 按岛归一化（r19 最关键的一条）

- **图集是 3690 个 UV 岛拼的马赛克**（中位 69 texel、离边界中位 5、最大 75.3）→ 201 窗口能
  整窗落在同一岛内的纹素 **0.0%**：局部空间背景处处不成立。
- **按岛归一化**（逐岛中位归零 + σ 取本岛离散度 `q75(|L−岛中位|)/1.1503`）已实装：
  真机 **2.18%/35 处 → 0.24%/7 处**、3.5 s→2.9 s、注入仍 9/11。
- **先归零再填充**（反过来岛边界重新长台阶）。
- 不用「块 σ > N×本岛尺度」判脏块：真机 p99=6.07 而 40 texel 斑块只有 4.7，分不开。
- 已知边界：**岛内病变过半会把病变当中位**（50% 击穿点固有）。「N 处」只能读作
  **待复核处数不是病害数**。
- **阈值方向是死路**：全局 k 3.5→4.5 图斑 7→4 但 80 texel 注入覆盖 0.92→0；按岛自适应
  `clip(岛内 z 的 p99, k, 6)` 图斑 7→2 但召回 9/11→4/11（自我指涉：缺陷就是那条尾巴）。
  自适应已实现、**默认关**，报表渲染 k 区间。要真提升得用与 z 无关的第二类证据
  （形状/连续性/跨期 X4）。
- 合成 12 项：6~120 texel 边界 IoU 全 1.00；纯净/σ=1.5 噪声 0.000%；条纹旋转关纹理不命中、
  开 ≥0.7。

## 编排与出口

- **阶段 `X3` 在 `M4→P1→X3→M5`**，顺序只在 `_reorder_ext_stages` 一处钉（报表在 M5 里生成，
  排后面指标永远进不了报表）。默认开（`runner.x3_enabled=True`）但归 `OPTIONAL_STAGES`
  （坏图只降级）；**不进质量门**（「病害多」≠「建模失败」）。
- 指标三出口同步：`manifest_metrics` → `accuracy.csv` → HTML/论文表，少一个就是 r16 那个坑。
  结论绑 `anomaly_atlas_digest`（`atlas-vN` 只有档案继承时才有）。

## 色度分域（D15）

- `chroma_in` / `chroma_ring` / `domain(paint|bare|unknown)`，**看环不看内部**
  （掉彩露胎本身是胎体色、周围才是彩绘）。阈值 15、环宽 8。
- 真机 paint_ratio **1.89%**、7 处全 bare、彩绘区 0 处。
- **必须用原始 Lab 算色度**（归零后的 a/b 不在 128 中心 → 中性灰块算出 190）。
- **「图案边缘」判据被数据否决**：7 处 Lab a/b=127~130 全无彩，而 chroma>15 只占 1.88% 面积
  ——判据没有作用对象。几何也分不开（真机 10.8~17.1 宽、密度 0.35~0.71 vs 方块 12~120 宽、
  密度 1.00，方向还相反）。

## 结构性陷阱（已踩两次）

- **图斑列顺序唯一来源 `REGION_FIELDS`**：`as_row()` 与 CSV 表头都读它。手写两份会漏列，
  真机抛 `dict contains fields not in fieldnames`（r16 同构）。
- **GUI「异常筛查」页**：读模型 `h3d/anomaly/summary.py`（无 Qt，三态 ok/missing/corrupt）
  + 面板薄装配。`missing` 必须印「未筛查」**绝不说成 0 处**。并排「原图｜热力图」
  （热力图说哪里、原图说是什么）；裁剪边距按 `max(w,h)` 给（长条裂隙否则被裁成横线）。
- **验收看截图不看测试**：坐标列默认 100 px 会折三行、占比两位小数把 7 处压成同一格
  ——都是测试全绿而截图不可读。
- 已知：**同一岛内彩绘边界也会被报**（局部中位数把深褐当背景），单期分不出
  「掉彩」与「图案边缘」。

## X4 时序追踪（ADR-0004）

- UV 空间、两期同布局（岛掩膜 IoU<0.99 抛错，靠 B1 继承）。
- 配对双门：bbox IoU≥0.1 **且** 质心 ≤1.5×半径和 → 匈牙利；五态（1.3 面积比）。
- **ΔE≥5 只卡非稳定态**。
- **两期照明对齐必须在 RGB 码值空间**（Lab 里 L 有立方根，线性变换变非线性，残差 4.4）。
  逐通道分位仿射，真机 +25 时稳定态 ΔE 9.80→0.00。代价：整件均匀色变被当光照减掉、
  暗部有 2 ΔE 量化下限、饱和裁切不可恢复。
- **X4 不做 runner 阶段**（跨两次运行 + 无基准期时永远 skipped，ADR-0004 D3）。
- **反向对照判据是「非稳定态为 0」不是「changes 为空」**（稳定态本来就该报）。
