### 关键设计决策
- **两段式配准**：FPFH+RANSAC 粗配准（无需初值）→ point-to-plane ICP 精配准。
- **E200 判定在 ICP 之后**：RANSAC fitness 对「无重叠」不可靠（mutual filter 回退导致虚假高 fitness），
  改用「精配准后 ICP fitness < 0.2」判重叠不足，正确配准≈1.0、无重叠<0.2，边界清晰且稳健。
- RANSAC 失败回退更粗对应距离重试一次（设计书 33.4）。

### 环境注意 / 踩坑
- Open3D 0.19 的 `RANSACConvergenceCriteria` 无 `max_validation` 参数，仅 `max_iteration/confidence`。
- 测试数据用「带凹凸的非对称球面」（对称形状 FPFH 特征无区分度会导致 RANSAC 歧义）。
- E200 测试初版用「同形状远距离」点云，因 FPFH 平移不变仍能匹配 → 改用「球面 vs 平面」；后又因
  fitness 0.09~0.11 跨越 0.1 阈值出现随机性 → 阈值调到 0.2 解决。

### 关键设计决策
- **核心闭环扩展为「点云 → 模型 → 质检」**：M1 预处理 → M2 配准 → M3 重建 → M5 质检（质量门 + 报告），端到端可跑通。
- **「几何质量可报告」能力**：60_qc JSON（机器可读）+ 70_report accuracy.csv（utf-8-sig 中文表头 Excel 可开）+ run_manifest 指标三路输出。
- **质量门阈值**（设计书 §36）：覆盖率 ≥ 80%（§6.3）+ 中误差 ≤ 5mm（WW/T 0115/0117 精细级），不达标状态 fail 阻断交付（E500）。
- **尺度自适应**（软著方案 2.7.2）：覆盖率判定阈值 = k × MPS（k=3 默认），不写死绝对距离。
- **rmse_reliable 工程化扩展**（设计书 §36.4）：表面采样 RMSE 受参考点云密度主导，稀疏扫描的 MPS 即达几十毫米；仅当 MPS ≤ rmse_threshold（参考足够密能分辨阈值量级偏差）时启用 rmse 判门，否则仅判覆盖率门。
- **STAGE_REGISTRY 无侵入接入**：`@register_stage("M5")` 一行装饰器，无需改动 BatchProcessor；后续 M4 同模式接入。
- **失败隔离一致性**：QualityGateError 继承 RecoverableError → 编排层 _isolate 记录失败清单 + 跳过该尊，队列其余照常处理（设计书 §6.3「不达标尊像不进入交付包」）。
- **先写报告再判定**：stage 先 build_report 落盘 qc_metrics.json + accuracy.csv，再判定 ok/抛 E500——失败也有据可查。
