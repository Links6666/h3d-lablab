# 2026-09-03

## 🐛 GUI「新建项目闪退」根因分析 + 修复（用户实际测试报告）

### 根因
PySide6 经典陷阱：welcome.py 槽内**局部变量** wizard/MainWindow show() 后无 Python 引用
→ GC 回收 → C++ 顶层窗口销毁 → 表现"点新建项目直接闪退"（打包版 console=False 无声更隐蔽）

### 修复（4 处）
1. welcome._start_wizard/_wizard_done/_open_selected/_start_demo → self._wizard/self._main 持有引用
2. 槽内 try/except → QMessageBox（不无声）
3. app.py matplotlib 延迟（MeshPreview import 入 _build_preview_panel）
4. diag.py：excepthook + faulthandler → ~/.workbuddy/h3d_gui_crash.log；launcher GUI 先 install_crash_guard()

### 验证
- GC 后窗口存活 ✅（offscreen 模拟点击）
- TestWelcomeNoGc 新增 2 项回归；全量 355 项通过
