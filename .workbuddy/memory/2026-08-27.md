### 关键设计决策
- **UV 路径核心**：顶点色不能支持 OBJ 纹理图集烘焙，UV 展开 + 图集烘焙是真实彩塑造像必备
- **xatlas MIT 许可**：符合软著方案白名单；parametrize 返回 (vmap, indices, uvs) 三元组
- **并发的工程关键**：worker 不写共享 manifest（避免多进程写冲突），主进程统一写；闭包/lambda stage 不可 pickle（Windows spawn）→ 内核 _strip_reserved 过滤保留键 + 测试用模块级 mock
- **HTML 单文件自包含**：jinja2 内嵌字符串模板（无 .html 文件依赖），图表 base64 嵌入→ 可离线分享
- **健壮性矩阵**：xatlas 失败降级、PLY 不支持纹理跳过、metrics 保留键过滤、worker 崩溃兜底

### 踩坑
- **metrics 含保留键冲突（关键修复）**：mock 测试用 `{"n":1, "stage":"M1"}` 与 manifest.record(stage=...) 冲突 → 加 `_strip_reserved` 过滤 stage/status/outputs/elapsed_s/item_id
- **闭包不可 pickle**：pytest 用 `_ok_stage("M1")` 闭包→ ProcessPoolExecutor 报 "Can't get local object" → 改用模块级函数
- **record_fail 存 reason 而非 message**：测试断言错误键 → 改为 `.get("reason")`
- **uv_pts 是 (S,2) 矩阵**：`image[py, px]` 索引广播失败 → 取 `uv_pts[:,0]`/`[:,1]`
- **ReportConfig 无 project_name**：HTML 报表需项目名 → 加字段并 CLI 传入
