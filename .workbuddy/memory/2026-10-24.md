## 澄清：用户所说「立体六面图」不是管线产物

- 用户在产物卡片里看到一张兵马俑六视角合成图，问是否管线生成。核查：
  `grep -rn "六面|six_view|turnaround|render_views|montage" src/ scripts/` **零命中**；

  `report/` 只有 report.html + metrics_summary.csv + stage_timings.png（耗时柱状图）。
  → **管线只出数据（几何+贴图+报表），没有任何多视角渲染器**（本机 Open3D 0.19 无 EGL 离屏）。
- 那张图是**客户端对 GLB 的 3D 预览卡片**（内置查看器多角度合成缩略图），模型本体是管线产物。
- GLB 实测（trimesh）：86099 顶点 / 117679 面 / UV (86099,2) 逐顶点 / 内嵌 2048² 贴图 /
  baseColorFactor 255 白 / metallic 0 roughness 1 / 包围盒对角线 6.067。
- M4 指标：projected_cameras=30、island_fill_ratio=0.9499、coverage_ratio=0.5867、
  atlas_utilization=0.6176、normal_flipped=False、normal_visible_fraction=0.9259、
  multiview_color_std=14.46、texture_mean_luma=77.19、pixel_scale=1.8741、elapsed=91.59s。
- 口径提醒：`coverage_ratio`=有效着色纹素/全图（58.7%），而 diffuse.png 直接按亮度>25 统计
  非黑像素得 80.3%——差值来自 `_bleed` 扩边（只防串色，不算着色），两个数不矛盾。
- 待办（用户未确认）：若要论文用六视角成图，需新增渲染器（自写软件光栅器，或 trimesh+pyrender/
  pyvista 离屏），输出正交六视 + 白底 + 比例尺。

## 20:00-20:25 M4 图集跨件复用 + 导出加速 + 泊松可复现（v1.1.6 / r10）

- UV 级键 = 几何指纹（float32 顶点 + int32 面，顶点顺序参与）；命中复用 `vmap/indices/uvs`，
