### 关键坑（均已解决/记录）

3. **逐像素渲染太慢**：改向量化光栅化（bbox 网格 + 批量重心插值）
4. **合成照片 SIFT 0 特征**：纹理过平滑 → 叠加高频（条纹+噪声+棋盘格）→ 每图 54~316 特征

6. **dense 失败根因**：系统无 CUDA Toolkit（cudart64_*.dll 缺失），PMS GPU-only → CUDA error (null)，exit 127；GPU 硬件存在（RTX 3050, compute 8.6, Driver 546.30）

## 续跑 dense 失败（驱动-版本不匹配）+ 无 CUDA 路线报告

### 结果
- CUDA Toolkit 12.3.0 确认安装成功（nvcc V12.3.52, cudart64_12.dll）
- 底层 CUDA 全链路验证通过：cuInit=0, cuDeviceGetCount=1 (RTX 3050, compute 8.6), cuDriverGetVersion=12030
- **dense 仍失败，根因：COLMAP 4.1.1（2026-07 构建）静态链接 CUDA 13 运行时 vs 驱动 546.30（CUDA 12.3）过旧** → CUDA error (null), exit 127；gpu_mat_test 4/4 FAILED
- 版本排查：4.x 全为 2026 构建（CUDA 13）；3.11.1（2024-12, CUDA 12 时代）无 Windows 二进制 → 无降级版可用
- 修复：用户更新 NVIDIA 驱动 ≥ CUDA 13（2026 驱动）；dense 工作区断点完整可续跑
- **PDF**：`output/造像类文物三维建模自动化系统_dense续跑与无CUDA路线分析报告_20260828.pdf`（12 页）

### 诊断要点（证据链）
1. ctypes 驱动 API 全成功（cuInit/cuDeviceGetCount/cuDeviceComputeCapability）→ 排除 Toolkit/驱动坏
2. pefile 分析 colmap.exe/gpu_mat_test.exe 导入表：无 CUDA DLL → **CUDA 静态链接**
3. 静态链接 CUDA 13 → 驱动版本检查失败 → (null)
4. Windows DLL 搜索：复制 cudart/cublas/cufft 到 colmap bin 无效（静态链接不依赖 DLL）

### 无 CUDA 纯 CPU 路线（报告第五章，用户核心要求）
- 原理：代价体 + 平面扫描（SAD/NCC/Census + winner-take-all + 深度融合），numpy 向量化
- 工具：OpenCV SGBM（Apache-2.0，推荐）/ MVE（BSD-3）/ 自研 plane-sweeping（论文创新点候选）/ OpenMVS（GPL 规避）
- 性能：10~50× 慢，建议 640×480~1024×768；CUDA 秒级 vs CPU 分钟级
- 双轨架构：CUDA（质量/速度）+ CPU（可用/可复现），符合 cuda.docx 降级容错设计
- 适用：主业务线（场景①）本就不需 dense；低配教学/CI；场景②高精度用 CUDA
