## B2 切片 13：色度分域（D15）—— 「图案边缘」判据被数据否决
用户要「图案边缘」判据。**先量数据，前提被推翻**，改为色度分域。

- 三条几何量全分不开：真机 7 处最粗宽 **10.8~17.1**（中位 14.1）、密度 0.35~0.71；
  合成方斑块最粗宽 = 边长（12~120）、密度 1.00。**真机比方块还细**，密度方向还
  相反——「不规则 = 不是病害」这条方向是错的（掉彩本来就不规则）。
- 决定性的一列：7 处 Lab 中位 **a/b = 127~130**（中性点 128），环色度 2.9~10.2；
  全岛 p50 4.1 / p95 12.4 / p99 16.8，**chroma>15 只占 1.88% 面积**。
  → 「图案边缘」只可能出现在 1.88% 的有彩区，**7 处没有一处在有彩区**：判据在
  真机上没有作用对象（不是不准，是样本不存在）。也反过来说明这 7 处不是掉彩
  （掉彩要求周围是彩绘），是胎体表面的明暗差。
- 改为**域分类**：`chroma_in` / `chroma_ring` / `domain(paint|bare|unknown)`。
  **看环不看内部**——掉彩露胎本身是胎体色、周围才是彩绘，只看内部会正好判反
  （合成用例钉住）。阈值 15、环宽 8（≈ 真机图斑最粗宽的一半）。
- 真机：paint_ratio **1.89%**、7 处全 bare、彩绘区 0 处报警。三出口一致
  （manifest / accuracy.csv `1.89% / 0` / HTML 明细「域」列 + 脚注）。
- 三个坑：① 用**归零后**的 Lab 算色度 → 中性灰块算出 chroma=190 被判「彩绘」（必须用
  原始 Lab）；② CSV 表头手写 9 列而 `as_row` 已 12 键 → 真机抛 `dict contains fields
  not in fieldnames`（r16 同构）→ 提成 `REGION_FIELDS` 唯一来源；③ 「域」列只有 31 px
  把中文省略成「胎…」（`ResizeToContents` 在空表上按表头度量）→ `setMinimumSectionSize(44)`。
- 全量 1183 项绿。

## B3 前置：X1 首次真机验证（4 个缺陷）+ S0 数据可行性探测（ADR-0005）

### X1：启用真机，5 次尝试，4 个缺陷（判据「同源两期 max_change≈0」）
| 次序 | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | skip | 硬拼 `10_dense/<件>/fused_dense.ply`（那是 COLMAP 稠密点云）；**激光件几何在 30_dense** | `_current_geometry()` 候选链 |
| 2 | 1181mm | 网格 PLY 被 `read_point_cloud` 读成**顶点**（不报错），分布极不均匀 | 先当网格读，有三角面就均匀采样（「≥100 点」门槛拦不住：小球 114 顶点刚好过关） |
| 3 | nan（全 NaN） | 核心点铺在 **XY 平面**（Z 常量），立体文物上网格与表面错开 | 核心点改成**从点云抽样** |
| 4 | 450mm | `estimate_mps` 抽样后算间距 → 放大 sqrt(200k/20k)=3.16 倍（真机 20 万点报 16.2mm，实际 4.83mm） | 抽样后按 `sqrt(m/n)` 校正；判据「MPS 不应随 sample_limit 变」 |
| 5 | **177mm 仍未达标** | 疑似 normal_radius=49mm 跨面 / max_distance=245mm 过大 | **未修**，需标定而非猜参 |

- 现状：**能跑但不可信**（同源两期 177mm，而两期点云实测互最近邻中位 4.83mm）。
- 因此加 `ChangeConfig.calibrated`（默认 False）：未标定时 accuracy.csv 与**论文表**的
  X1 列印「未标定」而不是数字——「能引用才给数」的纪律，与 X3 的 `rmse_scope` 同源。
- **附带发现**：X1/X2 排在 M6 之后 → 报表/论文表**读不到本轮**结果，论文表慢一轮
  （实测第一次仍 177.33，第二次才「未标定」）。与 D8 同一个病，X3 当年就是为此插到
  M5 前。本批**不动顺序**（要同步 GUI 顺序/两套权重/测试，风险>收益），但 S0 接线前必须解决。

### S0：1.1.12 **标不出训练数据**（决定性结论）
- 取 X3 的 44 个 ≥24 texel 连通域里最大 16 个裁图（4×4）+ 全图 1/4 缩略，逐格判读。
- 结果：**全是「UV 岛边界 / 材质交界」**（浅灰白胎体 ↔ 深褐土渍/残彩，边缘锐利），
  **无裂隙（细长黑线）、无起翘/脱落（带阴影翘边）**；全图是褐色+灰白斑驳，无贯穿缺陷。
- 残存彩绘仅 **1.89%**（chroma>15 面积比）。硬标只能得「彩绘/胎体」二类 = D15 已做的域分类，无增量。
- 结论：**阻塞在数据，不在代码**。S0 接口/环境现在就能开（4GB 显存够），但需要一件
  病害形态明确的文物（裂隙/起翘脱落/污渍/胎体孔洞），至少 2~3 类各若干实例。
- 没装 MobileSAM/torch（约 2.5GB）——**先验证「有没有东西可标」再上工具**，这次又躲掉一次空跑。
