### 经验（可复用）
- Inno Setup 脚本含中文路径/文件名时，`.iss` **必须存为 UTF-8 with BOM**，
  否则 Inno 按 ANSI 解析导致中文乱码或找不到文件。用 PowerShell
  `[System.IO.File]::WriteAllText($p,$c,(New-Object System.Text.UTF8Encoding $true))` 处理。
- 同理 `README_快速开始.txt` / `VERSION.txt` 也加 BOM，保证记事本正确识别。
- `cp -r packaging/` 会把 `packaging/Output/` 里 236MB 旧安装包一起复制（source 快照
  一度膨胀到 227MB）→ 归档源码时务必排除 `Output/`。
- PowerShell 的 `Add-Type` 被沙箱拦截（禁止运行时编译加载 .NET）；
  校验 zip 改用 managed python 的 `zipfile.testzip()`。
