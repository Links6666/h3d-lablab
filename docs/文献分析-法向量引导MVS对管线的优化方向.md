# 法向量引导 MVS 对 H3D 的优化方向

> 分析对象：①《基于法向量引导的复杂几何文物三维重建方法》（刘建祥等，图学学报
> 2026-09-23 网络首发，13 页）；②《文献评估_法向量引导MVS_管线价值评估》（本项目
> v1.1.11 时期编制的评估报告，15 页）。
> 当前管线版本 1.1.25（r31），测试 1462 全绿。
>
> 本文不是第二份评估报告。上一份回答的是「这篇论文能不能用」，本次回答的是三个新问题：
> **它报的数字和我们报的数字是不是一回事、上次提的建议落地了几条、接下来该做什么。**

## 0 分析口径

三件事先说清，否则后面的结论会被误读。

1. **一手资料优先。** 论文原文与评估报告冲突时以论文为准；报告里的所有数字都已回原
   表核对（含 DTU 表 1、自建表 3/4、消融表 5、法向质量表 6）。
2. **评估报告是 v1.1.11 时期写的**，当时管线还没有 `normal_agreement`、没有定种子、
   没有 `texture_overlap`。所以报告第 4 章的部分判断已被后续版本部分兑现，第 4 章给出
   逐条审计，不再重复表扬。
3. **「优化方向」只算能落地成代码或采集动作的**。凡是“应该更懂原理”这类不算方向。

## 1 论文事实卡

先把论文压成一页，后面所有判断都基于这张表。

| 项 | 内容 |
|---|---|
| 方法名 | NG-MVSNet（Normal-Guided MVSNet），由粗到精三级级联（1/4、1/2、1） |
| 输入 | 1 个参考视图 + 4 个源视图，640×512，相机内参 K 与外参 R,t |
| 几何先验 | **单目法向图**（Omnidata 从参考图像预测），不是点云法向 |
| 模块一 NGFE | 法向 → 缩放/偏置参数 (γ,β) → 特征仿射调制；局部法向一致性 c 越低，调制越接近恒等 |
| 模块二 NCAW | 用 3×3 邻域法向一致性 q 对逐视图相似度体**逐像素加权**：`w = 1 + tanh(α)(0.5−q)`，α 初始 0 |
| 模块三 JPGR | 法向先验 + 上一阶段置信度（停梯度）联合校准代价分布，残差门控多尺度 |
| DTU 结果 | Acc 0.335 / Comp 0.237 / **Overall 0.286 mm**；GoMVS 为 0.327/0.251/0.289 |
| 自建文物 | 5 类 6 件（砖雕、青铜壶、鸟尊、瓷器、玉龟、唐三彩），**每类 100–200 张环绕**，佳能 90D |
| 自建真值 | **HandySCAN 700 扫描仪点云**，ICP 配准后平移分量均 <0.15 mm，Final RMS 0.3–0.8 mm |
| 自建结果 | 均值 Acc **0.840** / Comp **0.189** / Overall **0.515 mm** / F-Score 0.908（阈值 1 mm） |
| 消融 | 基线 0.309 → +NGFE 0.303 → +JPGR 0.296 → 两者 0.291 → +NCAW **0.286**（较基线 −7.4%） |
| 法向质量敏感性 | GT 0.280 / Omnidata 0.286 / MiDaS 0.295 / **无先验 0.309** |
| 开销 | 峰值 8343 MiB；相对 GoMVS 显存约 −50%、推理约 −38% |
| 作者自陈局限 | 依赖单目法向估计质量；只在室内文物场景验证 |

三点值得单独拎出来：

- **它的提升主要来自 Comp（完整度）而不是 Acc（准确度）**。0.237 vs 0.251 是补出了更多
  有效点，0.335 vs 0.327 甚至略差。换句话说：**法向先验治的是“缺”，不是“偏”**。
- **消融的增量很小**：−7.4% 是三级累加的结果，单个模块只有 0.006 / 0.013 / 0.005 mm。
  这在 DTU 这种 0.3 mm 量级的数据上已经是可测差异，但它不是“数量级改善”。
- **它自己做了法向质量敏感性实验**：用 GT 法向 0.280、用较差的 MiDaS 0.295。这条实验的
  价值大于主结果——它说明**先验不完美也能用，但先验质量会传递到结果**。

## 2 关键认知：0.286 mm 与我们的 9.07% 不是一回事

这一节是全文最重要的一节。如果这一点不说清，后面所有对比都会跑偏。

| | 论文 | 本管线 |
|---|---|---|
| 报什么 | 重建点云到**真值**的距离（Acc 单向、Comp 单向） | `rmse`：模型到**自己**的点云的距离 |
| 真值来源 | HandySCAN 700 扫描（0.02 mm 级），ICP 后 RMS 0.3–0.8 mm | **没有真值** |
| 口径 | 外部基准，可跨方法横比 | 内部自洽，只说明“模型和输入一致” |
| 数值 | 0.515 mm（自建文物均值） | `rmse_rel` 9.07%（relic_001，包围盒对角线占比） |

**两者不可比，差距首先在“有没有真值”，不在“算法好不好”。**

论文有真值，所以能说“我比 CasMVSNet 好 72.7%”；我们没有真值，所以只能说“这次比上次
一致”。这也是为什么 M5 的 `rmse` 一直挂在「不判门（单位存疑）」——不是算法不行，是
**缺一把外部尺子**。

顺带一个反直觉的推论：论文的 Final RMS 0.3–0.8 mm 说明**连它的评估本身都带 0.3 mm
以上的不确定度**。当被测差异小于评估不确定度时，任何“提升了 0.006 mm”的说法都不成立。
这条对我们的意义是：**先解决尺子，再谈精度**。

## 3 与现有管线的逐项对照

### 3.1 它有、我们没有

| 论文能力 | 我们的现状 | 差距性质 |
|---|---|---|
| 单目法向先验（图像→法向） | 只有几何法线（`estimate_normals`，依赖点云密度） | **新能力**，但需 GPU 与模型许可；且我们的瓶颈不在法向 |
| 代价体级几何约束（JPGR） | 无代价体（M3 是泊松全局求解） | 架构不同，不适用 |
| 100–200 张/类环绕采集 | relic_001 只有 **30 张**，且只有 11 台位姿可用 | **采集差距**，最硬的瓶颈 |
| HandySCAN 真值 + ICP 残差链 | 无真值 | **评估能力**，可借（借一次扫描即可） |
| 逐模块消融（基线 → 逐项加） | 有前后对照，缺逐项增量 | **写法差距**，零成本可补 |

### 3.2 我们有、它没有

这一栏同样重要，避免“读完论文就自卑”。

| 我们的能力 | 论文是否有 |
|---|---|
| 两期形变比对（X1/M3C2 + 同源闸门 + 已知形变标定） | 无 |
| 单期纹理异常筛查（X2 按岛归一化 + 图斑清单） | 无 |
| 照片投影贴图全链路（UV + Z-buffer + 多视图加权 + 接缝） | 无（它只到点云） |
| 交付核验与口径体系（`rmse_scope`、`units_plausible`、verify 23 项） | 无 |
| 断点续跑 / 内容指纹 / 图集版本冻结 | 无 |
| 可复现性（四个随机消费者定种子 + 守卫测试） | 未提及 |

**它是一条“更好的稠密重建”，我们是一条“能交付、能比较、能追溯的管线”。**
定位不同，不必在同一维度上比高低。

## 4 上轮五条建议的落地审计

评估报告第 4–5 章提了五条可落地建议。逐条查代码，结论如下。

| # | 上轮建议 | 现在的状态 | 证据 |
|---|---|---|---|
| 1 | `io/mvs` 后端契约（COLMAP / 未来后端可替换） | **未落地** | `src/h3d/io/` 只有 `mesh_io` / `pointcloud_io` / `rng` |
| 2 | 法向一致性加权进 M2 对应点筛选 | **只做了一半** | 有 `normal_agreement`（全局标量，判方向），无逐点 `c` 与加权 |
| 3 | 恒等回退原则（不可靠就退回不干预） | **已落地** | `already_aligned` 回退恒等、朝向闸门拒绝、对齐 `in_frame_ratio` 掉一半回退 |
| 4 | X1 置信度逐级收紧（LOD 分层二次判定） | **未落地** | `lodetection` 已读出，但没有分层二次判定 |
| 5 | 跨期第六项：重建后端版本冻结 | **未落地** | `grep backend_version` 无任何结果 |

**1 条落地、1 条半落地、3 条未落地。** 这不是批评上一轮——而是说明一个更普遍的问题：
**评估报告产出的“行动项”没有进入待办体系，也没有判据钉住，所以自然消失了。**

同构的经验在这个项目里出现过很多次（手写白名单、单一真源、随机消费者）。所以本次给出的
方向，每一条都必须带**可执行的判据**，否则半年后同样是零。

## 5 优化方向

排序原则：**先补尺子，再补可逆性，最后补精度**。理由见第 2 节——没有尺子时，“更准”
无从验证；不可逆的架构决定（后端契约）越晚做越贵。

### 5.1 P0：零依赖、本周可做（3 条）

**P0-1 立 `io/mvs` 后端契约（只落 COLMAP 一个实现）**

- 做什么：`MvsBackend.reconstruct(images, K, R, t, cfg) -> DepthMaps | FusedCloud`，
  把 `sfm_solve` 里调 `patch_match_stereo` + `stereo_fusion` 的那段搬进
  `io/mvs/colmap_pm.py`。
- 为什么现在做：论文把 `(K,R,t)` 当输入这一事实，反过来证明**稠密重建与位姿估计可以按
  契约切开**，而位姿正好是 S1 的输出。契约定了，“换后端”才是配置项而不是改代码。
- 判据：同一份项目配置，走契约与走原路径产出的 `fused_dense.ply` **哈希相同**；
  `pytest` 全绿；`h3d verify` 23 项不变。
- 成本：半天。收益：把一个不可逆的决定变成可逆的。

**P0-2 M2 加逐点法向一致性加权**

论文式 (2)：`c = (n̂ · n̄ + 1) / 2`，`n̄` 是邻域均值法向（点云上用 k-NN 或半径邻域，
半径取 2–3 倍平均点距；不能用图像的 5×5 窗口）。加权用 NCAW 的形式：
`w = 1 + tanh(α)(0.5 − c)`，**α 初始 0 → w ≡ 1**，即上线时行为与现在完全一致。

- 用途：ICP 对应点加权，或 `c < 0.6~0.7` 的对应点直接剔除（FPFH+RANSAC 的错配集中在
  折角、边缘、法向突变处，这正是 `c` 低的地方）。
- 为什么与现有 `normal_agreement` 不重复：那个是**配准后**判“方向对不对”的全局标量
  （闸门用）；这个是**配准前**判“这个对应点该不该信”的逐点量。一个治错解，一个治错配。
- 判据（缺一不可）：
  1. `α=0` 时五档注入（7/30/90/120/180°）旋转误差与现在**逐位相同**——证明零影响；
  2. `α` 打开后，低重叠场景（target 切到 60%，fitness 0.2329）的 fitness **不下降**；
  3. 真机 `test111.ply` 连跑两次 `max|ΔT| < 1e-12`（可复现性不能破）。
- 成本：半天。风险：法向质量差时会放大噪声，所以必须先做 P1-1。

**P0-3 后端标识进资产元数据与指纹**

- 做什么：`CanonicalAsset.params` 增 `backend_id` / `backend_version`，并把两者并入
  内容哈希输入；manifest 的 M2/M3 记录同步。
- 为什么：这是评估报告第 5 章“第六项跨期约定”的落地前提。**没有它，半年后查不清
  “这期是哪个后端跑的”**，而不同后端的偏差是系统性偏置，LOD 吃不掉，整片弱纹理区会被
  判成“变化”。
- 判据：同一项目跑两次，`backend_version` 一致；手动改一位后 `content_key` 变化；
  `verify` 增一项检查（有产物但无 backend 标识 → WARN）。
- 成本：2 小时（主要是把它接进指纹与报表）。

### 5.2 P1：需要半天到一天（3 条）

**P1-1 法向可靠性前置检查**

论文的表 6 说明：法向质量会传递到结果（GT 0.280 / MiDaS 0.295，差 5%）。我们的几何法线
在**单面扫描**上本就不稳（外向归一要靠投票，实测 source/target 符号可能整体相反）。
所以加权之前先报一个 `normal_quality`：邻域一致性 `c` 的中位数、法线跳变占比。

- 判据：`normal_quality` 中位数 <0.7 时，M2 **关闭加权**并在报表标「法向不可靠，
  按未加权处理」——这是恒等回退原则在新模块上的复用。
- 成本：半天。避免“用一个不可靠的量去做加权，结果比不加权更差”。

**P1-2 M4 融合权重加法向一致性项**

现有权重是 `w = cos²θ / (1+dist) × pen`，`pen` 只有可见性（可见 1.0 / 遮挡 0.05）。
论文 NCAW 的思路可以平移到贴图：在**法向剧烈变化处**（纹饰边缘、折角）降低单视图权重、
提高多视图融合比例，减少接缝。

- 判据：真机 relic_001 上 `texture_overlap` 不降、`multiview_color_std` 下降或持平，
  且 `island_fill_ratio` 不降（0.8264 是现状基线）。**三个数必须一起看**，只看色差会
  把“只有一台相机在看”当成改善。
- 成本：半天。收益：可能改善接缝，也可能无变化——所以先做小样本 A/B。

**P1-3 评估不确定度链：让 `rmse` 从“不判门”升一档**

论文的做法可以直接借：**真值 + ICP 残差本身作为评估不确定度**（它报 平移 <0.15 mm、
Final RMS 0.3–0.8 mm）。我们不需要买扫描仪，只需要**一次借用的高精度扫描件**。

- 做什么：`rmse_scope` 增一档「真值判门（评估不确定度 ±X mm）」；X 取自真值配准残差。
  报告数字时必须带这个 ±。
- 判据：有真值时，`rmse` 参与毫米门但**必须同时印出 ±X**；无真值时维持现状（不判门），
  不许因为“有了新档位”就把旧数据抬进毫米门。
- 成本：一天（含一次真值配准）。**这是把 9.07% 变成可引用毫米数的唯一路径。**

### 5.3 P2：需要数据或硬件（2 条）

**P2-1 采集密度：30 张 → 100 张以上**

论文每类 100–200 张环绕，我们 relic_001 是 30 张，稀疏点 13,990、`track` 3.95。
**这是当前最大的单点差距**，而且它不是算法问题。

- 判据：同一件文物重拍后，`track` 中位数 ≥6、`dense_novel_ratio` 提升、
  镂空/内侧的纹素「靠反面填充」比例从 **22.3%** 明显下降。
- 成本：一次采集。收益：比换任何算法都大。

**P2-2 弱纹理与薄壁分区重建**

论文的第三个难点是「深度不连续边界」。我们的对应物是薄壁、镂空、纹饰边缘——泊松在这些
地方留洞，贴图靠反面填充。可行的做法不是换重建算法，而是**按法向突变分割后分区调
`poisson_depth`**，再合并。

- 判据：薄壁区的孔洞面积下降，同时整体 `coverage_ratio` 不降（不能靠“把洞补成平面”骗指标）。
- 成本：1–2 天，且需要 P2-1 的数据才有意义。

### 5.4 明确不做（三条，附理由）

| 不做 | 理由 |
|---|---|
| 集成 NG-MVSNet | 无代码、无许可、峰值 8.3 GB（本机 4 GB）；且它只替代稠密一段，其余环节一件不少 |
| 追 DTU 的 0.286 mm | 那是**有真值**条件下的数；我们没有真值，追这个数等于追一个无法验证的目标 |
| 把“法向一致性”当万能判据 | 论文与我们的 ADR-0025 都碰到同一条边界：**近凸/轴对称物上翻转与正解几何等价，判不出**。它是“多一个证据”，不是“解决朝向问题” |

## 6 论文可直接用的素材

| 素材 | 用法 | 出处 |
|---|---|---|
| 「COLMAP 在弱纹理与光照变化下匹配不稳定」 | 作为**为什么需要多后端/多证据**的引文，不是“所以我们也要做深度学习” | 论文引言 |
| 逐模块消融表（基线 0.309 → 0.286，−7.4%） | 我们论文的表格模板：**每个判据贡献多少，用同一基线逐项加** | 论文表 5 |
| 法向质量敏感性（GT/Omnidata/MiDaS/无先验） | 支撑「先验不必完美，但必须先量它有多可靠」——正好对应 P1-1 | 论文表 6 |
| 真值 + ICP 残差作为评估不确定度 | 支撑我们第 10 章「数字能不能引用」：**先报尺子的不确定度，再报被测值** | 论文 2.3.2 |
| 「A 路线与 B 路线差一个数量级，且不因换网络而消失」 | 支撑我们“激光做基准、影像做高频复测”的定位 | 评估报告 5.4 |

## 7 一页结论

1. **论文不是竞品，是一面镜子。** 它有真值、有 100+ 张采集、有逐模块消融；这三样正是
   我们缺的三样，而**没有一样是靠写代码能补的**。
2. **0.286 mm 与 9.07% 不可比**：一个是到真值的距离，一个是自洽程度。差距首先是尺子。
3. **上轮 5 条建议只落地 1 条**，原因不是判断错，是**没有判据钉住**。所以本次每条都带判据。
4. 下一步按 P0-1（后端契约）→ P0-3（后端标识）→ P0-2（逐点法向加权）→ P1-1（法向可靠性）
   走，四条都在一天内，且都不依赖新数据。
5. **真正决定这套系统上限的仍然是采集**：30 张 vs 100–200 张，`track` 3.95 vs 应有 6+。
   算法侧的优化空间已经很小了。
