# ADR-0014：ICP 对齐要多个旋转初值，且尺度必须有约束

- 日期：2026-11-03
- 状态：已实装（`geo_align._axis_rotations` / `_icp_similarity_once`）
- 前置：ADR-0013（位姿约定修正）暴露出这个缺陷

## 现象

位姿修正后，激光网格与 SfM 模型确认不同系（`10_dense` 100% 入画、激光件 0%），
必须靠对齐拉到一起。`align_points_to_mesh` 报：

```
对齐后源点云包围盒是网格的 0.43 倍（允许 0.70~1.30）
——相似变换没有收敛到同一尺度
```

而两边的 99% 分位对角线本来只差 3%（6.04 vs 6.20），初始尺度估计是 0.966。
**尺度却掉到了 0.43。**

闸门行为是对的（宁可不动也不搬错），但它让对齐永远走不通，纹理覆盖率 0%。

## 归因：单初值 + 无约束尺度

同一份数据，用 24 个立方体群旋转各跑一遍 ICP，只保留旋转平移（尺度固定为
初始值 0.966）：

| 初值 | 中位最近邻 / 对角线 |
|---|---|
| **单位阵**（原实现唯一初值） | **112%**（完全没对上） |
| 最优旋转初值 | **2.5%**（可用） |

也就是说：COLMAP 世界系的坐标轴由建图过程决定，与激光扫描仪**没有关系**，
两者相对朝向可以是任意旋转。单位阵初值在这种情况下必然卡死在错误的局部极小。

卡死之后，Umeyama 会沿着错误对应把尺度往下拉（1.0 → 0.43），于是被闸门拒。
**尺度漂移是症状，初值是病因。**

## 实装

1. **24 个旋转初值**（`_axis_rotations`：坐标轴置换 × 符号，det=+1），每个独立
   跑完整迭代，取**最终中位最近邻**最小的；
2. **尺度夹带**（`_SCALE_BAND = (0.6, 1.6)`）：若某一步累积尺度会越界，就当作
   「这一步没估出尺度」、保持不动。让旋转去找解，而不是让尺度去凑；
3. 变换组合按 `centred = s0·(X−C) + M` 推严格：
   `s = s_c·s0`、`R = R_c`、`T = s_c·R_c·(M − s0·C) + T_c`，保证
   `(s, R, T)` 仍是作用在**原始**点上的相似变换（语义不变）；
4. metrics 新增 `scale_init`，与 `scale_s` 并列——**「估出来的尺度」和「初始
   尺度」差多少**本身就是可判据（差太大时就该怀疑解）。

代价：24 × 6 次迭代 ≈ 2 s。

## 效果（真机，同一份输入）

| 指标 | 修前 | 修后 |
|---|---|---|
| 对齐结论 | rejected（包围盒 0.43） | **applied**（control_points + nearest_refine） |
| `in_frame` 对齐前 → 后 | — | **0.0% → 100.0%** |
| `projected_cameras` | 11/30 | **30/30** |
| `cameras_blind` | 19/30 | **0/30** |
| `coverage_ratio` | 0.0 | **0.6332** |
| `island_fill_ratio` | 0.0 | **0.9998** |
| `multiview_color_std` | 32.67 | **16.06** |

（第一版实装漏了把初值旋转 `R0` 折进累积变换，测出的是 0.5517 / 0.9020 /
13.62——**返回的 `(s,R,T)` 复现不出它自己算出的点**，于是"最优候选"按返回的
变换算回去比单位阵还差。合成数据上看不出来，是
`test_returned_transform_reproduces_the_working_set` 逐点比对才暴露的。）

最后一行值得单独说：**多视图颜色离散度降了 58%**。过去几天一直在追的「岛间
色调跳变」被归因为「照片之间白平衡不一致、缺色卡」，还为此做了曝光归一化
（只降 11%）和完整光度校准（−0.2%，ADR-0012）。

真相是：**19 台相机根本没有投上、剩下 11 台又是错位姿**，所谓「同一条纹素在
不同相机下颜色差得远」，有很大一部分是「那些相机根本不在看这个位置」。

ADR-0012 的结论（线性光度校准无效）仍然成立——它测的是「相机增益差异」，
中位 0.0% 是实测。但它给出的**归因**（差异来自场景/光照，只能靠采集）需要
按这一条修正：先保证位姿对，再谈光度。

## 未决

  岛与岛之间的边界依旧是主要伪影源。
- `normal_visible_fraction` 0.72（< 90 % 阈值）——网格局部法线不一致，这是
  下一处可查的点。
- 真机 `capture_meta.json` 仍是老格式，建议重跑 S1 重新生成。
