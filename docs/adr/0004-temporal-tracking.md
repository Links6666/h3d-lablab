# ADR-0004：X4 病害时序追踪（两期图斑关联 + 五态）

- 状态：已实施（切片 1）
- 日期：2026-10-31
- 相关：ADR-0003（X3 单期异常检测，尤其 D12/D13）

## 背景：为什么必须换证据类型

X3 在真机图集上给出「0.24% 岛内面积 / 7 处待复核」。想把 7 压下去的两条路都试过、
都量过、都是零和：

| 手段 | 图斑 | 注入召回 |
|---|---|---|
| 全局 k 3.5 → 4.5（D12） | 7 → 4 | 9/11 → 7/11（80 texel 覆盖率 0.92→0） |
| 按岛自适应 k，上限 6.0（D13） | 7 → 2 | 9/11 → **4/11** |

原因是**误报与真检在同一强度尺度上不可分**：任何只在「单张图的异常分」上做文章的
判据，都只是在同一条曲线上左右移动。

X4 换的是**证据类型**：同一个物理位置在两期之间到底变没变。噪声不会两期都变，
真病害会——这条信息在单张图里根本不存在。

## 决定

在 UV 图集空间做两期比对，输出五态：

| 状态 | 含义 | 保护处置 |
|---|---|---|
| 新增 | 第二期才出现 | 干预 |
| 扩大 | 面积比 ≥ 1.3 | 加密监测 |
| 稳定 | 两期都在，面积变化 < 30% | 继续观察 |
| 缩小 | 面积比 ≤ 1/1.3 | 干预有效 |
| 消失 | 第二期不再报警 | 可结案 |

三个关键参数，都由合成两期注入标定（`tests/test_anomaly_temporal.py` 11 项）：

1. **配对**：bbox IoU ≥ 0.10，且质心距离 ≤ 1.5 ×（两图斑等效半径之和）——
   两道门都要过（或其中一道）。只有 IoU 会把「长条形扩大」判成两个新病害；
   只有距离会把相邻的两处独立病害粘成一条。
2. **面积变化门限 1.3**：线尺度约 14%，与 UV 采样误差同量级的下限。
3. **可见性门限 ΔE ≥ 5（CIE76）**：低于它说明两期像素几乎没动，**「变没变」这件事
   本身不成立**，报出来只会是阈值抖动。这条门限只作用于「非稳定态」——稳定态
   本来就该 ΔE 小（同一处病害一直没动）。

## 为什么是 UV 空间而不是三维 M3C2

原计划（MEMORY 里的 X4 记法）是「显著性用 M3C2 LoD95 + 最小图斑面积」。本切片
先在 UV 空间做，理由：

- M3C2 需要两期**各自**的几何与配准，误差会叠加进显著性判断；UV 空间只需要
  两期共用一套布局，比较是逐纹素的，误差项少一个量级。
- 前提是 B1 的**图集继承**（基准 mesh/uv/faces + 复测相机走同一采样器、不重新展开）
  ——这时「同一物理点 = 同一纹素」。这条前提由代码强制
  （`:func:`h3d.anomaly.temporal.track` 比对两期岛掩膜，IoU < 0.99 直接抛错），
  不靠文档提醒：布局一变，所有跨期结论连带作废。
- 三维 M3C2 仍是**几何**变化的正确工具（剥落、裂隙深度），留给 X1 那条线；
  本层回答的是**表面外观**的变化，两者互补而不是替代。

## 真机验证（第二期为仿真）

`scripts/verify_x4_temporal.py`：拿 1.1.12 的图集当第一期，改三处已知位置生成
第二期，逐行核对真值：

| 真值 | 实测 | 关键数字 |
|---|---|---|
| 新增 @(1558,1718) 36 texel | ✓ 新增 | 1296 texel，中位 ΔE 63.1，所在岛 σ=7.8 |
| 扩大 @(939,1746)-(983,1816) 外扩 10 texel | ✓ 扩大 | 1103 → 2280 texel，面积比 2.07 |
| 消失 @(996,31)-(1018,75) 涂回岛中位色 | ✓ 消失 | 529 texel，中位 ΔE 21.2 |
| 其余四处不动 | ✓ 稳定 ×4 | 面积比 1.00，ΔE 0.00 |

**反向对照**：两期完全相同 → 7 条「稳定」、**0 条非稳定态**。这一条比正向用例更
重要——X4 的失效模式是「把噪声当病害变化」，那会直接导致错误的保护处置。

CLI：`h3d anomaly-track -p <项目> --item <件> --a <图集A> --b <图集B>`，
产物落 `60_qc/<件>/temporal/{changes.csv, summary.json}`。

途中返工两次，都记在这里：
1. **第一次反向对照写错**：把「两期相同」判成「0 条变化」——不对，稳定态本来就要
   报（那是「这处病害还在」的记录）。判据应是「非稳定态为 0」。
2. **「新增」第一次没测出来**：注入点选在 σ≈19 的大岛上，ΔE 66 只有 3.5σ，正好压
   在检测门限上。改选 σ<8 的岛后 ΔE 63 就是 8σ，一次命中。这条与 X3 的可检下限
   一致，不是 X4 的问题。

## D2 两期照明对齐（默认开）

### 问题是被量出来的

把**同一张**真机图集整体提亮 25 个码值，内容一个像素都没变：

| 扰动 | 对齐 | 非稳定态 | 稳定态 ΔE 中位 | 对齐后残差 ΔE |
|---|---|---|---|---|
| 整体提亮 +25 | 关 | 0 | **9.80** | 10.63 |
| 整体提亮 +25 | **开** | 0 | **0.00** | 0.00 |
| 对比度 ×1.35 | 关 | 0 | 4.75 | 10.51 |
| 对比度 ×1.35 | **开** | 0 | 1.00 | 1.00 |
| 整体压暗 −20 | 关 | 0 | 8.24 | 9.02 |
| 整体压暗 −20 | **开** | 0 | 0.00 | 0.00 |

注意五态判定**没变**（X3 的岛内归一化把常数抵消了）——受害的是 **ΔE 那一列**：
报表会印出「这处病害加重了 9.8 个色差」，而它一像素没动。这一列在换灯之后就
不可读了，而它正是 X4 用来判「变化是否可见」的依据。

### 做法

逐通道**分位仿射**（配 q10/q90 尺度 + 中位偏移），只在岛内估计，增益夹在
[1/2, 2]。

- **在 RGB 码值空间做，不在 Lab**：曝光和白平衡作用在传感器 RGB 上，
  「整体提亮 25 个码值」在 RGB 里正是一个平移；换到 Lab 后它变成非线性
  （L 有立方根），用 Lab 的仿射只能减掉一部分——实测残差 **4.4 ΔE**，
  仍然足够印成「病害变了」。
- **分位而不是最小二乘**：最小二乘会去拟合少数病变（正是我们要看的东西），
  把「病害变亮」当成「整体变亮」减掉。
- **只在岛内**：岛外是未着色黑底，会把 q10 拉到 0、增益估成 2 倍。
- **仿射而不是只减偏移**：换灯往往同时改对比度，只减偏移挡不住（上表第二行）。

### 代价与边界（三条，都写进报表口径）

1. **整件均匀变色会被当成光照减掉**。这层追踪只报**局部**变化——一件文物整体
   泛黄通常来自灯/白平衡，不来自病害；真要评整体色变，走 X2 的 ΔE 色差（有
   色卡基准）。
2. **8 位量化在暗部被 Lab 放大**：RGB 差 1 个码值，在 L≈30 处就是约 2 个 ΔE。
   所以对齐后残差不可能是 0，验收阈值按 3 个 ΔE 给（合成用例实测 2.2）。
3. **饱和裁切不可恢复**：第二期若过曝，被裁掉的高光任何仿射都还原不了。
   这类区域结论应当降级——目前只是不额外处理，靠 ΔE 残差指标（`delta_e_residual`）
   暴露整体异常。

度量随结论一起报：`light_align`（是否对齐）、`light_gain` / `light_offset`
（逐通道，offset 单位是 8 位码值）、`delta_e_residual`（对齐后岛内中位 ΔE，
同源内容应 ≈0；明显不为 0 说明两期差异不是纯光照，或者根本配错了图集）。

## 已知限制（必须随结论一起给出）

- **第二期是仿真的**，不是真的复测扫描。它验证的是「关联 + 状态机 + ΔE 门限」这套
  机制，**不能**替代真实两期数据。真实数据还要验：UV 继承的像素级配准误差、两期
  光照/曝光差异、真实病害的缓慢变化（几个月才涨几个纹素）。
- **光照是烘进纹理的**：已按 D2 做两期分位仿射对齐（默认开），真机实测把稳定态
  ΔE 从 8~10 压回 0~1。但它是**码值域的近似**：整件均匀色变会被当光照减掉、
  饱和裁切不可恢复、暗部有 1~2 ΔE 的量化下限。第一次真实两期时仍应同时拍色卡
  （X2），用色卡基准交叉核对对齐结果。
- 五态只回答「变没变、变大变小」，**不给病害类别**（类别属 S0）。
- 匹配用 bbox 而不是精确掩膜 IoU：区域数量少、形状紧凑时够用；细长/分叉的图斑
  可能配错，需要时可换成交并比。

## D3 为什么 X4 **不**做成 runner 阶段

原本的计划是「接进编排层：`X4` 阶段 + 两期目录 + 报表段落」。动手前改了这个判断，
理由是形态不对，不是工作量：

- **runner 的组织单位是「一次运行 = 一个 epoch」**（一个 manifest、一套
  `50_tex/<件>/`、一组阶段终态）。X4 的输入**跨两次运行**，硬塞进阶段表会出现
  「本阶段只读本阶段的产物」这条契约被打破。
- **它只在一个条件下有意义**：本项目已经存在**基准期**。绝大多数首次建模根本
  没有第二期，做成阶段的结果是每次运行都 `skipped: 无基准期`——一个永远不执行
  的阶段比没有更糟（它会出现在报表的「跳过」计数里，稀释「跳过」这个信号的
  含义）。
- 现在 `h3d anomaly-track --a --b` 已经能把两期比对做完，缺点只是**要手工指路径**
  而不是「按 epoch 名自动找」。这个缺点在真实第二次采集之前无法验证。

**等真实第二次采集时按这个形态接**（写在这里，避免下次重新讨论）：

1. 基准期取档案里的 `archive/epochs/<id>` + `atlas/<ver>`（B1 已有），本次运行
   产出新一期；
2. 新增 `X4` 阶段，判据是「档案里存在早于本次的 epoch」，否则 `skipped/condition`
   （与 X3 缺图集同一套语义），并且**归 OPTIONAL_STAGES**——比对失败不该否定本次
   建模；
3. 产物落 `60_qc/<件>/temporal/<基准期>__<本期>/`，报表新增一节；
4. 首次真机必须同时拍色卡，用 X2 的 ΔE 交叉核对 D2 的对齐结果。

在此之前，**不要**为了「看起来接了」而加一个永远跳过的阶段。
