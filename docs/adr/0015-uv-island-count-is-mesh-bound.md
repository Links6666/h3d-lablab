# ADR-0015：UV 岛数不是展开参数造成的，调参这条路走不通

- 日期：2026-11-03
- 状态：**不实装**（测量后决定不改代码）
- 背景：X3 的残余图斑仍以「UV 岛边界」形态为主，曾计划「减少岛数」来降噪

## 问题

真机这件文物的图集有约 1900~2400 个 UV 岛（73k 面的网格），X3 检出的 7 处
图斑裁图看仍是岛边界/未着色缝隙。原计划是「调 xatlas 让岛少一些」。

## 测量（同一份 `30_dense`：36781 顶点 / 73222 面）

### 1. ChartOptions 全扫一遍，岛数只在一个窄带里动

| 参数 | 岛数 | 利用率 |
|---|---|---|
| 默认 | 1890 | 79.4% |
| `max_cost` = 3 / 5 / 10 / 1e6 | 2177（**四个值完全相同**） | 82.4% |
| `normal_deviation_weight` = 1.0 / 0.5 / 0.2 | 2074 / 2387 / 2315 | 82% |
| `straightness_weight`=1, `normal_dev`=0.5 | 2122 | 82.2% |
| 四项权重全设 0 | 2107 | 63.9% |
| `max_chart_area` = 0.5（限制更小） | 1710 | 74.4% |

**整个参数空间的跨度是 1710~2387（±15%）**，一个数量级都换不来；形变指标
（UV 与 3D 面积比的 p95/p5）始终 1.12~1.14，即**这个网格本来就几乎不形变**，
不是"用形变换岛数"的取舍问题。

选项确实生效（`max_chart_area=0.5` 让岛数掉到 1710、利用率掉到 74.4%），
只是**敏感度极低**。

### 2. 法线完全不起作用

| 传给 xatlas 的法线 | 岛数 |
|---|---|
| 原始 | 1890 |
| Laplacian 平滑 5 / 20 次 | 1890 / 1890 |
| **强制全部 +Z**（极端对照） | **1890** |

天真的假设「切图沿法线不连续」被否证：xatlas 在这里根本不看我们给的法线。

### 3. 对照实验：换几何才动，换参数不动

| 几何 | 面数 | 岛数 |
|---|---|---|
| 标准球（resolution 60） | 14160 | **7** |
| 立方体（细分 3） | 768 | **6** |
| 真机 `30_dense` | 73222 | **1890** |
| 真机**简化到 2 万面** | 20000 | **103** |

球 7 个岛 → xatlas 与调用方式都正常。同一件网格**简化 3.7 倍，岛数掉 18 倍**。

### 4. 平滑反而更糟

Taubin 平滑 5 / 10 / 20 次 → 岛数 2523 / 2637 / 2800（越平滑越碎）。

## 结论

**岛多的根因在网格，不在展开算法。** Poisson 用约 6.4 万个激光点重建出 7.3 万个面
（≈1.14 面/点），表面被过度三角化，处处是高频起伏；xatlas 只能在这些起伏之间
切岛。任何"不动几何只调展开"的办法都到不了数量级。

## 决策：不改

- **不引入简化/平滑来换岛数**：这个网格同时是 M5 精度与 P1 纹理的载体，
  动几何等于动测量结果。用"把文物磨平"换"异常检测好看"不划算。
- **不动 xatlas 参数**：±15% 的岛数变化换不来可观测的 X3 改善，却引入一个
  默认值变化（与 `hole_fill_px` 那次同类：动了参数，收益未验证）。
- X3 的岛边界伪影作为**已知口径**保留：报表与论文里「N 处」只能读作
  **待复核处数**，不是病害数（ADR-0003 已记）。

## 真正可动的杠杆（留给下一阶段）

**M3 的泊松参数**（`depth` / `point_weight` / `density_quantile`）：在**保持
点云覆盖率**的前提下减少过度三角化，能同时改善岛数与三角形质量。这是几何
上游的问题，需要单独一轮测量（改完必须重新核 M5 的 rmse 与曲率）。

## 复查方式

```bash
.venv_lab/Scripts/python.exe output/_build/probe_uv_charts.py
```

脚本会打印各参数下的岛数 / 利用率 / 形变，以及对照几何体的基准值。
