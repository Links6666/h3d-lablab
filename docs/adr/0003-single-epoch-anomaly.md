# ADR-0003：单期纹理异常检测（B2 / X3）

- 状态：已接受
- 日期：2026-10-31
- 相关：`src/h3d/anomaly/`、`tests/test_anomaly_detect.py`、`tests/test_cli_anomaly.py`

## 背景

指南第 3 章（记 X2）要求对**单期**标准化 UV 纹理图做无监督离群筛查：回答「这里是否
异常」，不给病害类别。代码命名空间里 `X2` 已被 ΔE 色差占用，故本模块记 **X3**。

输入只有 M4 已产出的一对图：`_L1.0_diffuse.png`（多视图加权票决的图集）与
`_L1.0_mask.png`（岛内掩膜）。**不重走位姿**——重投影会引入另一套误差源，
而这一层要回答的是「这张图本身可不可疑」。

四个方向由用户在开工前拍定：

| 决策点 | 选定 |
|---|---|
| 算法路线 | 统计离群（分块 Lab 特征 + 稳健 z），不引入学习 |
| 检测空间 | UV 图集空间（不重走 M4 位姿） |
| 接线层 | 先 CLI（`h3d anomaly`），验完再进 `STAGE_REGISTRY` |
| 验收判据 | 合成注入 + 反向对照（IoU ≥ 0.7、最小可检 ≤ 2% 边长、平滑纹理异常面积 < 0.5%） |

## 决策

### D1 判据必须是「注入 + 反向对照」，不是「看着像」

无监督检测最典型的失败不是漏检，而是**整件都异常**：热力图色彩丰富、看着很专业，
其实什么都没检出。所以每个正向用例都配一条「异常面积占比必须很小」的界，反向
用例（纯净渐变、σ=1.5 噪声）要求异常面积 ≈ 0。

### D2 背景必须是**局部中位数**，不是均值、不是裁剪均值

这是本模块唯一一条经过三轮返工的决策，过程值得记下来：

1. **块级均值 + 中位数/MAD**（第一版）：合成全绿，真机 24 texel 斑块覆盖率 1.00
   但 **IoU 0.14**——掩膜只能落在 16 纹素块格上，斑块外溢 7 倍；80 texel 的整块
   斑块反而漏检（块内均值把小于块的位移稀释掉）。
2. **裁剪均值**（先取均值，剔掉超阈值者再平均）：窗内病变占比 36% 时，均值被拉偏
   `0.36ΔE`，多数派的残差恰好就是 `0.36ΔE`、离群者是 `0.64ΔE`——两者只差 1.8 倍，
   任何 `3σ` 门限都筛不掉，裁剪形同虚设（120 texel 斑块在 201 窗口完全漏检）。
3. **局部中位数**：击穿点 50%，不依赖这个比值。用 `cv2.medianBlur`（8 位图走直方图
   滑窗，O(1)/纹素，2048² + ksize=201 实测 99 ms 且**与核长无关**）实现。

踩过的坑：**逐像素二分求局部中位数不成立**。二分让每个像素各带一个阈值 `mid(p)`，
而窗口计数必须用同一个阈值才自洽，于是 `(a <= mid)` 里 a(q) 配的是 mid(q)，算出来的
既不是 p 的中位数也不是任何人的中位数——真机实测阈值已降到 −72，窗内「过半」的计数
却纹丝不动（恒为 0.538），二分一路滑到区间边界，背景被判成 ∓amp、全图 z 归零。
`medianBlur` 的核长上限是 255（OpenCV 5.0 大核路径断言 `k < 16`，传 401 直接抛
`cv2.error`），要用更大尺度得先降采样。

### D3 尺度用**块内 75 分位**，脏块用邻域值**替换**而不是封顶

- 分位数在**块内**精确计算再双线性上采样（`W/4` 边长）：尺度是空间慢变量，不该
  逐纹素跳变；`np.percentile` 精确且比 `median_filter` 便宜一个量级（0.16 s vs 2.7 s）。
- 用 **75 分位**而不是中位数：中位数在**双峰**残差上会落到 0。周期纹理（条纹、织纹）
  的 `|残差|` 恰好一半为 0、一半为幅值——中位数取 0，尺度被 `min_scale` 接管，
  于是每条条纹的一半都判异常（合成条纹图实测 6.3% 岛内纹素误报）。75 分位落在
  幅值上，除以 1.1503（高斯 `q75(|r|) = 1.1503σ`）即得尺度；孤立斑块（占块内 5%）
  的 75 分位仍是 0，灵敏度不受影响。
- **脏块替换**：块内尺度超过邻域中位数 2 倍时，整块判为「被病变自己写脏」，直接用
  邻域值取代。封顶（`min(块值, 2×邻域)`）只把它压到 2 倍邻域值——在本来就粗糙的
  区域仍是 60，ΔE=120 的斑块只得 z=2 漏检；替换则是把它降到邻域本来的 30。
  代价是误报上升（真机 0.74%→2.18%），已量在下面。

### D4 多尺度取**最大分**，不取平均

三个背景窗口（31/81/201 纹素）各算一遍，逐纹素取最大：小窗负责 8~30 texel 的细节，
中窗 30~80，大窗 80~150。单一大窗会把「与窗口尺度相当的斑块」当成背景的一部分，
单一小窗看不到大斑块。

两路证据（颜色残差 / 纹理）之间也取最大、不取平均：颜色突变与纹理中断是两类独立
证据，取平均会让「另一路完全正常」把当前路稀释掉（早期实测 120 texel 的平涂色斑
在 15 维平均下从 10.9 掉到 2.96，直接漏检）。

### D5 纹理通道用结构张量，不用 LBP

先按指南的「LBP 描纹理」实现过一版（8 邻域码的 popcount 分布，9 维）。实测
区分不了「周期条纹」与「随机噪点」——条纹每像素横向 2–4 次跨越、纵向 0 次，
噪点平均 4 次，两者 popcount 分布大面积重叠，分值差不到 1 个 MAD。真相是 popcount
**丢掉了方向信息**，而方向一致性才是「原有织纹」与「被打断」的区别。

结构张量一致性 `sqrt((Jxx-Jyy)² + 4Jxy²)/(Jxx+Jyy)`：条纹 1.00 / 噪点 0.10。
方向另占两维 `(cos2θ, sin2θ)`——把竖条纹整体转成横条纹，均值方差完全一致、
一致性仍是 1.0，只有方向差 2.0。

三道闸门缺一不可：当前纹素有结构、基线有足够健康证据、**基线本身也一致**
（`|平均单位向量| ≥ 0.5`）。少了最后一条，混合方向的邻域里平均向量模长趋近 0，
把它当「另一个方向」会让整片各向同性纹理全部报警。

### D6 基线要**排除可疑区**，纹理证据只在颜色没响应的位置补位

- 方向基线用能量加权的圆均值，且估计时把块级可疑区排除。不排除的话，斑块附近的
  基线窗口一半是斑块方向一半是背景方向，圆均值落在中间，**两侧都**被判「方向变了」
  ——实测掩膜在斑块外糊出约 100 texel 的晕（覆盖真值 1.00 但掩膜 10436 texel，
  IoU 0.61）。排除后基线就是周边健康纹理的方向，斑块外 diff≈0、斑块内 diff≈2。
- 同一处病害若颜色也报了，边界**以颜色为准**（逐纹素精确），纹理那一路的边界只有
  16 纹素块粒度——两者叠加会在色斑外多出一圈 5~10 纹素的「方向变了」（60 texel
  的反色斑块实测 bbox 从 170 外扩到 160）。按「离颜色区超过一个块边长」筛掉。

### D7 面积只给纹素占比

`area_units="texel_ratio"`。换算 cm² 需要「每纹素对应多少 mm²」，那要网格 + 尺度
锚点（件号级），由调用方决定要不要做——**无度量基准的照片重建件不得冒充物理面积**
（同「无度量基准不得缩放」一条纪律）。

### D8 接线：排在 M4 之后、**M5 之前**，默认开，失败只降级

三个位置都是被约束逼出来的，不是排序偏好：

* **必须在 M5 之前**：报表是 M5 生成的（`build_report`），排在后面等于指标
  永远进不了报表。而它又只读 M4 的图集 —— 两头夹死，位置只有一个。
* **默认开启**（`runner.x3_enabled=True`，与其他可选阶段相反）：只读已有图集、
  2048² 实测 3.3 s/件，而它是唯一会主动指出「这版图集哪里可疑」的环节。
  关闭时走 `disabled` 并给出可读原因（`配置关闭：runner.x3_enabled=false`），
  不能与「有图但没跑」混成同一句。
* **失败只降级**（归 `OPTIONAL_STAGES`）：它读的是上游产物，可能坏文件/被占/
  半写。为一份附加筛查否定已经建好的模型，代价与收益不成比例 —— 阶段内部
  兜住所有异常，退成 `skipped` 并把原因写进 `skip_reason`。
* **绝不进质量门**：判据仍是覆盖率/中误差。一件有好几处真实病害的文物，
  建模本身可以完全合格；把病害多算成「建模失败」，等于让 QC 反过来惩罚被
  检查的对象。测试 `test_anomaly_does_not_touch_the_quality_gate` 钉住这条。

**指标有三个出口，少一个就是 r16 那个坑**：`manifest_metrics`（手写白名单，
不写进去就等于没算）→ `60_qc` / `accuracy.csv`（`build_report` 取数）→
HTML 与论文表（`thesis_tables` 另读 manifest）。实测 1.1.12 三处一致：
`2.18% / 35 处 / 图集摘要 5c1f4a1e6473`（按岛归一化之后是 `0.24% / 7 处`，D11）。

`anomaly_atlas` + `anomaly_atlas_digest`（图集文件内容摘要前 12 位）是「这条
结论基于哪一版图集」的唯一凭据 —— 版本号 `atlas-vN` 只有走档案继承时才有，
直接重跑 M4 换掉图集并不会改号。这一条顺带关掉了原「未决」里的
「异常结论没绑图集版本」。

### D9 把「可检下限」变成一个数字：`anomaly_sigma_median`

「灵敏度随局部信噪比变化」是句正确但没用的话。同一个 ΔE，在 σ_L=15 的地方是
6σ 异常、在 σ_L=53 的地方只有 2σ —— 所以指标里带上**本件在最粗尺度上的 σ_L
中位数**（Lab 单位，只取 L 通道：a/b 在多数图集上本来就平，取错通道会让它永远
等于地板 2.0，这个 bug 被测试抓到过）。

读法写进报表脚注：`σ_L≈14.5` 的意思是「本件典型位置的局部纹理跨度约 14.5
Lab 单位」，比它小一个量级的差异不要指望检出；真机 1.1.12 漏掉的两处正好在
σ_L=30 / 53 的区域，是**整件中位数的 2~3.6 倍**——数字能直接对上结论。

三个出口照旧同步：`manifest_metrics` → `accuracy.csv` → HTML（与异常面积同格
显示 `0.24% / σ_L≈12.2`，不额外加列）。论文表**不放**这个数：它是上下文，
不是结论。

### D10 图斑明细进报表（可折叠块，不动章节编号）

`regions.csv` 里一直有完整清单，但报表只给「35 处」——为了看一处边界框去翻
CSV，等于这层筛查停在「跑过一次」。做法：X3 把**前 10 处**（`_ANOMALY_TOP_N`，
按面积降序，与 CSV 同序）的 bbox / 纹素数 / 占比 / 均分放进
`anomaly_top_regions`，经 M5 白名单进 manifest，报表在第三节后渲染成
`<details>` 块——页面不被撑长，后面的章节编号一个都不动。

只带前 N 而不是全部：manifest 是指标不是日记；完整清单仍在 `regions.csv`，
块内注明了去处。

**这一片顺带查出了一件更要紧的事**：把前 3 处的 bbox 裁出来看
（`(206,1978)-(277,2041)` 等），它们是**一块亮 UV 岛被一圈暗小岛包围**——
不是病害，是岛间反照率差。

根因在方法论层面：**UV 图集里的相邻纹素在实物上并不相邻**。所以「局部背景」
跨岛取值在物理上没有意义；跨岛比较必然把「这块岛的底色与邻居不同」当成异常。
同一件事的另一面就是前面记过的岛边界假残差（腐蚀 0/2/3/5/8 只能把误报从
2.18% 压到 1.21%）。

对应的修法是**按岛归一化**：每个岛的纹素只与**它自己那个岛**的中位数比，
跨岛不做比较。**已在下一片做完（见 D11）**：35 处 → 7 处、2.18% → 0.24%，
注入灵敏度不变（9/11）且更快（3.5 s → 2.9 s）。
**在此之前，报表里 35 这个数字应当读作「35 处待人工复核」，不是「35 处病害」**
——这一句已经写进报表脚注，并保留到 D11 之后（7 处同样只是待复核）。

### D11 按岛归一化：把「相邻纹素」换成「同一个岛」

**为什么必须**（`scripts/verify_x3_islands.py` 一条命令量出来）：

| 量 | 值 |
|---|---|
| 图集上的 UV 岛数 | 3690（中位 69 texel，p90 234，最大 147 223） |
| 到岛边界距离 | 中位 5.0 texel，p90 15.7，**最大 75.3** |
| 31 窗口能整窗落在同一岛内的纹素 | 10.3% |
| 81 窗口 | 1.0% |
| **201 窗口** | **0.0%** |

即：**这张图集上，最大的检测窗口没有任何一个位置能整窗落在同一个岛内**。
「局部空间背景」在这里不是「不够好」，而是**处处都不成立**——两条相隔一个
纹素的像素，在实物上可能隔着半张脸。上一批（D10）看到的三处「亮岛被暗岛包围」
就是它的直接后果。

做法两件事，缺一不可：

1. **位置**：每个岛先减去**它自己的中位数**，所有岛归到 0 再比较。注意顺序是
   **先归零再最近邻填充**——反过来（先填后减）岛外的填充值没减中位数，每条岛
   边界会重新长出一个人为台阶，原型实测误报 10.7%。
2. **尺度**：σ 直接取**本岛自身的离散度**（`q75(|L − 岛中位|) / 1.1503`），
   不再做任何块级分位数。

尺度这一步是试了四版才定的（都在同一张真机图集 + 同一批注入上量）：

| σ 口径 | 真机异常 / 图斑 | 注入命中（ΔE=120，24/40/80） |
|---|---|---|
| 块分位数 + 邻域中位数池化 | 3.34% / 71 | 10/11 |
| 块分位数（无池化） | 0.16% / <8 处（均 <258 texel） | 8/11 |
| **本岛原始离散度（采用）** | **0.242% / 7** | **9/11** |
| 本岛残差 q75 | 5.94% / 93 | 10/11 |

- 块分位数的问题：一块 16~50 纹素里装的是**几个岛**的纹素，分位数天然跨岛；
  而且被病变填满的块，σ 会跳到病变自身的对比度（40 texel 斑块在 W=81 上把
  σ 撑到 89）。补池化能救回灵敏度，但把邻岛的 σ 又混回来。
- 「本岛残差 q75」看着更对（量的是残差而不是含阴影的原始离散度），实测误报
  5.94%：一个岛里 25% 是真实粗糙区时，岛内 q75 仍落在平滑段，粗糙区随即整片
  误报。
- 试过用「块 σ > N × 本岛尺度 → 判定脏块并替换」代替池化：**分不开**。真机块
  比值 p99 是 6.07，而 40 texel 斑块填满块时只有 4.7（W=81，σ=89），落在分界线
  下面。cap=2/4/6 的真机误报是 1.88/1.22/0.80%，而关掉时 60/120 texel 注入的
  IoU 掉到 0.09/0.33 —— 这条路上没有同时成立的取值。

**代价与已知边界**：岛内病变面积超过该岛一半时，中位数被病变自己带走，归一化
会把病变当成本底（这是任何 50% 击穿点估计器的固有限制，不是实现缺陷）。真机
中位岛只有 69 texel，所以「一个占据半个小岛的斑块」看不见。报表脚注已写明。

**这 7 处仍然只是「待复核」**。把 bbox 裁出来画上掩膜轮廓
（`output/_build/x3_island_top4_mask.png`）看到的是「浅色斑块紧邻深褐彩绘」——
在彩绘陶俑上这既可能是掉彩露胎（真病害），也可能只是来自未上色部位的岛。
没有像素级真值就不断言，这一条与 D10 一致。

顺带被测试抓到的两个真 bug：① `score_max` 统计了**岛外**纹素（一块干净图集的
`score_max` 由 3.52 而非 1.29 决定）→ 指标改为只在岛内取；② 逐岛尺度只取 L
信道（取「最后一个通道」会让它恒等于地板 2.0）。

## 取舍与已知边界

- **真机灵敏度随局部信噪比变化，不只看 ΔE**。同一 ΔE=120 的斑块，在平滑区域
  覆盖率 1.00、增量 IoU 0.96~1.00；在暗袍/亮高光交界附近（局部纹理跨度大）覆盖率
  只有 0.2。这是「z 是相对量」的必然结果，写报告时不能只写「可检出 ΔE≥X」。
- **大斑块反而更难**（80 texel 只 1/3）。**病因是实测出来的，不是推的**（2026-10-31
  诊断回路 `scripts/verify_x3_bigpatch.py`，同一图集三处同尺寸注入）：

  | 注入点 | 斑块残差 L（W=201） | 该处 σ_L | z_L | 结果 |
  |---|---|---|---|---|
  | (381,174) | 97 | 30.3 | 3.21 | 漏 |
  | (1589,511) | 97→106 | 53.2 / 84.8 | 1.82 / 1.25 | 漏 |
  | (1546,1720) | 100→113 | 15.7 | 6.37 | 中 |

  斑块残差在三处几乎一样（97~113）——**信号没丢，是分母涨了 5 倍**。之前 ADR 里
  猜的「脏块替换后邻域也被抬过一轮」被否掉了：注入点窗口内跨 20~31 个 UV 岛，残差
  沿斑块内部依然均匀。
  
  所以这是**低信噪比**，不是估计器缺陷。修复方向（「大斑块按面积累加证据」）会
  在材质交界处炸出大片假阳性——σ 大到 53 的原因正是那些交界。本批不动统计量，
  改为把可检下限**报出来**（见 D9）。
- **真机基线（按岛归一化之后，D11）**：异常 **0.242% / 7 处**、σ_L=12.17、
  2.9 s/件（关掉按岛是 2.181% / 35 处 / σ_L=14.52 / 3.5 s）。全部来自颜色通道；
  纹理通道在真机上零贡献（这件文物的纹理方向没有异常）。k 与图斑数的老标定
  （跨岛口径）：3.5 → 2.18%/35、4.5 → 1.12%/17、6.0 → 0.42%/8 ——按岛之后同样
  单调，k=3.5 仍是「先宽后窄」的起始档。
- **这件文物的图集是「3690 个小 UV 岛拼成的马赛克」，不是一块大岛**（D11）。
  曾经试过按腐蚀半径 0/2/3/5/8 排除岛边界（误报 2.18% → 1.77/1.56/1.35/1.21%），
  代价是赔掉 23%~64% 的可检面积 —— **那条路是错的**：边界只是症状，把「相邻
  纹素在实物上不相邻」当成几何瑕疵去剪裁，等于承认了错误的前提。按岛归一化
  才是解，见 D11。
- **连通域是散布型**：按岛口径 k=3.5 时全图 72 个连通域，≥24 纹素的 44 个；
  `min_region_ratio=1e-4`（2.58 M 纹素 → 258 纹素）再压到 7 个。也就是说真正
  起过滤作用的是**面积比阈值**，不是绝对纹素数下限（跨岛口径下这三个数是
  641/425/35）。
- **没有像素级真值**。7 处里哪些是真病害、哪些是没上色部位的岛，这件文物无从
  判定——真机结论只到「机制在 2048²/61.5% 岛内面积的真实图集上端到端成立、
  2.9 s/件、注入能被找到且边界增量 IoU ≥ 0.87（24/40 texel）」，**不到**
  「准确率 X%」。
