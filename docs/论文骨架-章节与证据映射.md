# 论文骨架：章节 ↔ 证据映射

> 这份文件的用途不是"写论文"，而是保证论文里每一句带数字的话都能指回一个**可复查的位置**。
> 写的时候按左列走，遇到右列空着的就停下来——那是还没做的实验，不是可以含糊过去的地方。
>
> 所有数字来自 `阶段成果/output/run_manifest.json`、`交付成果/report/accuracy.csv`、
> `docs/adr/`、`CHANGELOG.md`。**前提列不写清的数字不能引用**（本项目的头号纪律）。

## 0 一句话论点

> 面向中小型造像类文物，构建一条**可复现、口径可核**的自动化三维建模管线；
> 其贡献不在"能出模型"（开源工具链已能出），而在**让每个数字都带前置条件、条件不成立时拒绝给数**。

这条论点决定了论文的重心：方法章讲管线，**讨论章讲判据**。若把重心放在"精度多高"，
现有的真机数据撑不住（见 §3）。

## 2 可引用数字台账

前提列是这个表的全部价值。**同一件文物在不同配置下有三套数字**，混用就是学术不端。

### 2.0 这批数字对应哪一次运行

下面 §2.1 的数采自 **2026-11-04 的一次运行**：输入为 `D:/h3d_relic_test` 的
`00_raw/`、`00_photo/`（30 张）、`90_meta/relic_001_capture_meta.json`，
配置为 `sfm_solve.enabled=false`（复用既有位姿）、`texture.paint_mode=photo`、
`photo_texture.texture_size=2048`、`top_k=5`、`quality.coverage_threshold=0.30`。

**改动其中任一项，下表的值都要重跑并更新**，不能直接沿用——这正是本项目的头号
纪律。重跑方式见 §5。

> 反例就在手边：同一个 `relic_001`，另一套配置（跑 S1、位姿修正后 30/30 台可用）
> 得到的是 `coverage_ratio 0.5865`、`color_std 14.42`（见 `docs/adr/0013`）。
> 0.5865 与 0.5114 都是真的，**前提不同**。论文里必须写清是哪一套。

## 3 三处空白与降级写法

空白不是"写不出来"，是**必须换一种说法**。三处都已在代码里落了降级表述，论文照抄即可。

| 想要的结论 | 现在能写的 | 依据 |
|---|---|---|
| 配准精度 X mm | 算法级：注入 7/30/90/120/180° 旋转，复原误差 ≤0.02°；现场级：**未验证**（单站输入） | ADR-0014、`verify_registration_e2e.py` |
| 毫米级几何精度 | `rmse_rel`（中误差/对角线，无量纲）+ 明确写"要毫米级需激光基准或尺度控制点" | `quality/gate.py` 三态口径 |
| 病害检出能力 | "待复核处数" + "可检下限 σ_L"（本件典型局部纹理跨度）+ 明说不是病害分类 | ADR-0016 |

**写法示例**（可直接改成论文句子）：

> 本件几何中误差为包围盒对角线的 9.07%（无量纲）。由于包围盒对角线算得 8.46 m
> （超出中小型文物 0.02–3.0 m 的合理量级），坐标被当作米制使用时单位存疑，
> 该值不参与毫米级判定；若需毫米级结论，须核对输入点云的真实单位并提供激光基准
> 或尺度控制点（X2）。

## 4 答辩预案

| 可能被问 | 用什么回答 |
|---|---|
| "精度多少毫米？" | 不给毫米数。给 `rmse_rel` + 前置条件 + 为什么不能给（§3 第一行）。**这本身就是论文主张的一部分** |
| "配准验证过吗？" | 算法级注入实验（≤0.02°）+ 现场无两期/多站数据的事实。承认未验证，比含糊过去安全 |
| "覆盖率为什么只有 38%/51%？" | 11/30 台可用（位姿无效，ADR-0013 老账）；且 `island_fill_ratio` 82.6% 说明**不是法线/UV 问题**——两者配对读 |
| "色差 40.44 是不是融合做得差？" | 不是。同时刻 `texture_overlap` 5.77、`multi_view_ratio` 98.4%——融合有充足冗余，根子是可用相机太少（方法学 2.9） |
| "1400 项测试全绿，为什么还有缺陷？" | 方法学 §7 第 1 条：测试测的是"函数按我理解的方式工作"，而缺陷发生在"我的理解"这一层 |
| "创新点是什么？" | ① 自研贴图管线（逐纹素可见性 + 相机投票定法线）② 控制点引导 + 多初值 ICP ③ **判据体系**：让"这个数字能不能引用"成为机器可判的事实 |
