3.1 类与对象：把「一尊造像」封装起来
面向对象（OOP）的核心思想：把数据（属性）和操作数据的方法打包成一个「对象」。文保场景里，「
一尊造像」天然就是一个对象。
class Artifact:
    """代表一尊待数字化的造像。"""
    def __init__(self, object_id, raw_paths):
        self.id = object_id          # 属性：编号
        self.raw_paths = raw_paths    # 属性：原始扫描路径列表
        self.mesh = None              # 属性：最终网格（初始为空）
        self.reg_error = None         # 属性：配准误差
    def summary(self):
        """返回一句话摘要。"""
        n = len(self.raw_paths)
        return f"造像 {self.id}：{n} 站扫描，配准误差 {self.reg_error}"
# 使用
a = Artifact("luohan_001", ["s01.ply", "s02.ply"])
print(a.summary())
NOTE（要点）：__init__ 是构造方法，创建对象时自动调用；self 指代对象自身，所有属性和方法都要通过
它访问。

3.3 上下文管理器 with
处理大点云、文件、数据库连接时，务必在用完后释放。with 语句保证「退出时自动清理」，即使中途报

from contextlib import contextmanager
@contextmanager
def open_pcd(path):
    pcd = o3d.io.read_point_cloud(path)   # 进入时
    try:
        yield pcd
    finally:
        del pcd   # 退出时释放大内存

5.1 背景故事：一尊造像的数字化困境
某石窟寺需对一尊彩绘造像做三维存档：现场用结构光/激光扫描得到数十站、数百万到上亿点的点云，用
单反拍得数百张高像素 RAW 纹理。传统工作流把它们导入商业 GUI 软件（Metashape、CloudCompare、
Geomagic），人工逐站配准、手动去噪、手工重建网格、肉眼检查——一个熟练工程师处理一尊要数天。
• 痛点1 不可复现：同样数据换人换机，结果不同，论文里说不清「我怎么得到的」。
• 痛点2 不可批处理：十尊、百尊时手工流程崩溃，且无法保证一致性。
• 痛点3 算法黑箱：商业软件配准用什么方法、误差多大用户不知道，调参靠经验。
• 痛点4 成本与许可：商业软件按节点收费，且结果的法律属性（能否开源/软著）模糊。
NOTE（要点）：这些痛点解释了为何「用开源、可脚本、可复现的 Python 管线替代手工 GUI」对文保研
究生具战略价值：它把你和「只会点软件的技术员」区分开，是你的核心壁垒。

5.3 西南潮湿环境的特殊挑战【推断＋标准】
• 水盐 cycle：雨季水汽携带可溶盐（硫酸盐、硝酸盐）反复结晶—溶解，体积应力破坏地仗，引发酥碱、

• 设备与准入门槛：大场景激光扫描稀缺，系统以「摄影测量替代激光、院内结构光做高精度、借合作单

5.5 本文的解决办法：技术路线 E
技术路线 E 是用 Python + Open3D（+ py4dgeo） 复现并自动化导师商业软件工作流的开源管线，主张

• 可复现：同一 config.yaml + 同一原始数据，任何人重跑得同一结果。

# h3d/compliance.py（示意）
CHECKS = [
    ("点云特征点中误差<=5mm", lambda r: r.max_pt_err <= 5.0),
    ("可见区域覆盖率>=80%",   lambda r: r.coverage >= 0.80),
    ("相邻站重叠>=30%",       lambda r: r.overlap >= 0.30),
    ("纹理>=3400万像素RAW",   lambda r: r.tex_mp >= 34.0),
]
def audit(report):
    return {name: ("PASS" if fn(report) else "FAIL") for name, fn in CHECKS}
把 audit() 的结果写进 04_report/compliance.csv，作为成果验收附件——这正是「文保标准保障」的落

9.2 plyfile 的 GPL 隐蔽陷阱（重点）
plyfile 是最常用的 PLY 读写库，但其许可证为 GPL-3.0+。一旦 import plyfile 写进登记版源码，整个程
序可能被认定为 GPL 衍生作品，与「闭源登记/商用」冲突。
WARNING（注意）：规避方法：一律用 Open3D 的 o3d.io.read_point_cloud / write_point_cloud 读写
 PLY（MIT），不安装 plyfile。
# 错误示范（请勿在登记版使用）：
import plyfile          # GPL-3.0+，污染登记版！
# 正确做法：用 Open3D (MIT)
import open3d as o3d
pcd = o3d.io.read_point_cloud("luohan_001.ply")   # 安全
o3d.io.write_point_cloud("out.ply", pcd)
9.3 GPL 库的安全使用方式
• 子进程调用：subprocess.run(['CloudCompare', '-O', ...])，你的代码与 GPL 程序是独立进程，不构
成衍生作品。
• 声明与署名：在 NOTICE/文档中列出所用 GPL 组件及其许可证与获取方式（软著新规也要求标注开源
来源）。
• 不静态链接：绝不把 GPL 的 .so/.py 直接 import 进登记版主程序。

14.2 批量读取（glob 匹配）
import glob, os
def load_all(pattern):
    """读取匹配模式的所有点云，返回 (路径, 点云) 列表。"""
    paths = sorted(glob.glob(pattern))
    if not paths:
        raise FileNotFoundError(f"未匹配到任何点云: {pattern}")
    out = []
    for p in paths:
        out.append((p, load_one(p)))
    return out

配准是把多站点云变换到同一坐标系的核心步骤。本章用「FPFH+RANSAC 全局粗配准」加「ICP 精配准」

学习目标

16.1 两段式配准思路
直接 ICP 对初值敏感、易陷局部最优；先用全局特征配准给出粗略但稳健的初值，再用 ICP 精修。这正是

16.3 全局粗配准（RANSAC）
def global_register(src, tgt, fpfh_radius, ransac_dist, nnb=30):
    for pcd in (src, tgt):
        compute_fpfh(pcd, fpfh_radius, nnb)
    result = o3d.pipelines.registration.registration_ransac_based_on_feature_matching(
        src, tgt, src.fpfh, tgt.fpfh,
        mutual_filter=True,
        max_correspondence_distance=ransac_dist,
        estimation_method=o3d.pipelines.registration.TransformationEstimationPointToPoint(False),
        ransac_n=4,
        checkers=[
            o3d.pipelines.registration.CorrespondenceCheckerBasedOnEdgeLength(0.9),
            o3d.pipelines.registration.CorrespondenceCheckerBasedOnDistance(ransac_dist),
        ],
        criteria=o3d.pipelines.registration.RANSACConvergenceCriteria(max_iteration=200000),
    )
    return result

def poisson_mesh(pcd, depth=9):
    # pcd 需具备一致法线（见第15章）
    mesh, densities = o3d.geometry.TriangleMesh.create_from_point_cloud_poisson(

    mesh = mesh.remove_duplicated_vertices()

18.2 Hausdorff 距离（几何误差）
def hausdorff(mesh_a, mesh_b):
    """两网格采样点集的 Hausdorff 距离，作为几何误差指标。"""
    a = mesh_a.sample_points_uniformly(100000)
    b = mesh_b.sample_points_uniformly(100000)
    d_ab = a.compute_point_cloud_distance(b)
    d_ba = b.compute_point_cloud_distance(a)
    return max(max(d_ab), max(d_ba))
TIP（技巧）：Hausdorff 用于「重建网格 vs 参考网格」的偏差评估，也是与黄金基准交叉验证的指标之一。

19.1 尺度自适应与 MPS 倍数
不同尺度造像（掌印小龛 vs 大佛）应使用不同 voxel_size。本书以约 1 m 造像 voxel=2.0 mm 为基准（
MPS=1），更大对象按包围盒最长边比例线性放大倍数。
def adaptive_voxel(base_size_mm, bbox_mm, mps=1.0):
    """按包围盒最长边相对基准(1000mm)的比例，乘 MPS 倍数得 voxel。"""
    scale = max(bbox_mm) / 1000.0
    return round(2.0 * scale * mps, 3)
# 2.4 m 大佛, MPS=1 -> voxel≈4.8mm
print(adaptive_voxel(2.0, [2400, 1800, 1600]))

22.2 进度实时显示（信号槽）
上面用 communicate() 会等进程结束才显示。真实场景应异步读取，用信号把日志实时推到界面：
from PySide6.QtCore import QThread, Signal
class Worker(QThread):
    log_line = Signal(str)
    def __init__(self, config): super().__init__(); self.config = config
    def run(self):
        from subprocess import Popen, PIPE
        proc = Popen(["h3d","run","--config",self.config], stdout=PIPE, text=True)
        for line in proc.stdout:
            self.log_line.emit(line.strip())   # 实时推送到界面

NOTE（要点）：信号槽（Signal/Slot）是 Qt 的线程通信机制：后台线程跑管线，主线程更新界面，避免

26.1 M3C2 原理
M3C2（Lague et al. 2013）在核心点沿其法线方向，分别于两期点云做局部球状邻域最佳拟合平面，计算
法向距离差即为变化量；可附加误差传播（M3C2-EP, Winiwarter 2021）给出不确定度。py4dgeo（MIT）
原生实现 M3C2/M3C2-EP/PB-M3C2。
26.2 py4dgeo 调用
import py4dgeo
import numpy as np
t1 = py4dgeo.PointCloud(np.load("scan_2025.npy"))
t2 = py4dgeo.PointCloud(np.load("scan_2026.npy"))
core = t1
normals = np.load("normals_2025.npy")
m3c2 = py4dgeo.M3C2(core_points=core, normals=normals, working_distance=3.0)
distances = m3c2.compute(t1, t2)   # 正=外鼓/沉积，负=侵蚀
print("平均变化 mm:", float(np.nanmean(distances)))
26.3 误差传播（不确定度同报）
M3C2-EP 将两期各自局部平面拟合不确定度 propagate 为距离差总不确定度 σ。报告格式：变化量 d = 
-1.3 mm ± 0.6 mm，仅当 |d| > 2σ 才判为显著变化——这正是区分潮湿环境可逆形变与不可逆风化的关
键。
d = -1.3; sigma = 0.6
significant = abs(d) > 2 * sigma
print("显著变化?", significant)
26.4 实施要点
• 配准误差会直接污染差分 → 先用 CloudCompare/Open3D 把两期配准误差压到亚毫米。
• 潮湿环境可逆湿胀与不可逆风化难分 → 用「加速老化模拟样块 + 高频短周期(月)监测 + 历史 vs 现状
差分」组合。
• 环境变量（温湿度/水盐）耦合建模，量化不确定性，不报单一确定值。

27.2 色彩采集规范（对标 WW/T 0117—2023）
• 相机 ≥3400 万像素 RAW、每通道 ≥12 bit、色温 5500K±10%、标准色卡 ≥24 色。
• 每次同角度、同光照、同色卡；用 X-Rite 分光光度计定期校准显示器。
• RAW 工作流，色彩转换用相机特性文件，避免显示器相关空间直接比较。
• 跨时段 ΔE   追踪，建立彩绘层变色时间序列，作为技术规程产出。
27.3 色卡校准逐步流程
1. 每次拍摄前放 X-Rite 24 色卡于造像同光照平面，同角度拍一张含色卡的原图（RAW）。
2. 用相机特性文件（ICC）将 RAW 转 ProPhoto/Adobe RGB 线性空间。
3. 在色卡区域用已知 Lab 值做色彩校正，求本场次色差补偿矩阵。
4. 对目标区域取色，转 Lab 后跨时段算 ΔE  。
5. 将「拍摄参数+色卡图+补偿矩阵+ΔE   序列」写入 05_ext/color/，作为技术规程附件。

# h3d/input_qc.py（示意）
def qc_station(pcd, coverage, overlap, n_targets):
    """返回是否达 WW/T 0117 阈值。"""
    issues = []
    if coverage < 0.80:
        issues.append(f"覆盖率 {coverage:.2f} < 0.80")
    if overlap < 0.30:
        issues.append(f"重叠度 {overlap:.2f} < 0.30")
    if n_targets < 4:
        issues.append(f"标靶数 {n_targets} < 4")
    return issues   # 空列表表示通过

附录 B 术语表（Glossary）
点云 Point Cloud：由海量三维坐标点构成的对物体表面的离散采样表示。 配准 Registration：将多站/
多源点云变换到同一坐标系的过程。 FPFH：Fast Point Feature Histogram，快速点特征直方图，用于全
局配准描述子。 RANSAC：随机抽样一致，用于从含噪对应中估计稳健变换。 ICP：Iterative Closest 
Point，迭代最近点精配准。 泊松重建：由带法线点云生成水面网格的隐式重建方法。 M3C2：多时相点
云法向距离差分算法（Lague 2013）。 CIEDE2000：工业色差金标准公式，输出 ΔE  。 ΔE  ：两颜
色在 CIEDE2000 下的感知差异量。 酥碱：可溶盐结晶—溶解破坏地仗导致的粉化病害。 起甲：彩绘层与
地仗间因应力分离、卷翘的病害。 标准色卡：已知色值的参考卡（如 X-Rite ColorChecker ≥24 色），用
于色彩校准。 RAW：传感器原始未处理图像数据，保留最大色彩位深。 copyleft：一种许可证条款，要
求衍生作品以相同许可证开源（如 GPL）。 断点续跑：失败后仅重跑未完成任务、跳过已完成的能力。 失
败隔离：单个任务异常不影响整体批次继续执行。 run_manifest：记录批量任务每个 item 状态与溯源的 
JSON 清单。 软著：计算机软件著作权登记的简称。 职务作品：自然人执行单位任务所创作的作品，著作
权通常归单位（《条例》第 13 条）。 MTF / 标靶：配准用人工标志点，用于多站云拼接控制。 MPS 倍
数：本书尺度自适应策略：基准 voxel 乘以对象尺度比例的倍数。

附录 D 参考代码清单（完整可运行最小示例）
以下为一个端到端最小可运行示例（需先按第1、4章配环境，数据用 Stanford Bunny 练手）：
# quick_start.py —— 读入 -> 降采样 -> 配准(自比) -> 泊松重建 -> 保存
import open3d as o3d, numpy as np
pcd = o3d.io.read_point_cloud("bunny.ply")        # 公开数据集练手
pcd = pcd.voxel_down_sample(2.0)
pcd.estimate_normals(o3d.geometry.KDTreeSearchParamHybrid(6.0, 30))
pcd.orient_normals_consistent_tangent_plane(15)
# 自比配准演示：人为加变换后配回
T = np.eye(4); T[0, 3] = 1.0
moved = pcd.transform(T)
res = o3d.pipelines.registration.registration_icp(
    moved, pcd, 3.0, np.eye(4),
    o3d.pipelines.registration.TransformationEstimationPointToPoint())
print("ICP inlier RMSE(mm):", res.inlier_rmse)
mesh, _ = o3d.geometry.TriangleMesh.create_from_point_cloud_poisson(pcd, depth=9)
o3d.io.write_triangle_mesh("bunny_recon.ply", mesh)
print("模型已保存 bunny_recon.ply")
