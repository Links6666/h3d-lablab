第 1 章 项目背景与建设必要性
1.1 行业背景
石窟寺、摩崖造像与可移动彩塑造像是我国不可移动与可移动文物的重要组成部分。西南潮湿环境下，砂
岩质地造像普遍面临风化、渗水、盐析、生物侵蚀等病害，其形貌与表面信息处于持续劣化之中。三维数
字化是记录现状、支撑监测与虚拟修复、构建数字资产的基础手段，已被《WW/T 0117—2023 石窟寺文
物三维数字化采集技术规程》等标准明确纳入技术路线。 传统建模高度依赖商业软件（如
PhotoScan/Metashape、CloudCompare、Geomagic 等）的人工串联操作：导入、去噪、配准、稠密
重建、网格化、纹理映射、质检、导出，每一步均需人工判断与手工参数调整。当造像数量达数十乃至上
百尊时，过程不可复现、质量不稳定、工时难以估算，难以满足大规模抢救性数字化与周期性监测的需求。
1.2 现状与痛点
痛点
表现
对业务的影响
手工串联
多软件、多格式、多窗口人工切换
单尊耗时数小时，数百尊不可行
不可复现
参数散落在操作记忆与临时文件
无法审计、无法复算、难溯源
质量波动
依赖个人经验，缺统一质检阈值
成果良莠不齐，难以对照标准验收
数据治理弱
原始与中间数据混杂，缺目录规范
数据资产难以沉淀与再利用
合规风险
混用 GPL 与商业库，权属不清
软著登记与闭源分发存在风险
上述痛点可归结为“过程不可控、质量不可证、资产不可溯”三类根本问题，正是本系统要解决的核心。
1.3 建设目标
• 建设一套可批处理、可复现、可溯源的造像类文物三维建模自动化系统，覆盖“数据接入—配准—稠
密重建—网格纹理—质检—发布”全流程。
• 以纯 MIT/BSD 开源技术栈实现核心管线，规避 GPL 传染性风险，支持后续软件著作权登记与闭源分
发。
• 将精度与质量标准（WW/T 0117、WW/T 0115）内置为可校验的质量门，使成果“自带验收依据”。
• 提供图形用户界面，使非专业算法人员亦可按向导完成批量建模与质检。
• 建立 run_manifest 溯源机制，使每一份模型可回溯到原始数据、处理参数与软件版本。
1.4 建设价值
• 效率：将单尊建模的人工操作压缩为参数化的一次性配置，支持队列化批量处理。
• 质量：标准化流程 + 自动质检，成果一致性显著提升。
• 资产：溯源机制使数据资产可沉淀、可复算、可审计。
• 合规：技术栈与软著策略前置设计，降低法律与登记风险。
• 传承：方法以工具论文与代码托管形式留存，降低人员变动带来的知识流失。
1.5 与相关系统的关系
• 上游：外业采集规范（拍摄/扫描）产出图像与点云，本系统不负责采集。

15.1 粗配准
使用 FPFH 描述子提取关键点特征，以 RANSAC 估计初始变换，解决多站数据的初步对齐，对初始位姿不
敏感。
15.2 精配准
采用 point-to-plane ICP 进行多尺度迭代精化，逐级缩小容差，输出配准残差 RMS。残差作为配准质量
指标进入 manifest。
def register(a, b, cfg):
    fpfh_a = compute_fpfh(a, cfg['fpfh_radius_mm'])
    fpfh_b = compute_fpfh(b, cfg['fpfh_radius_mm'])
    T_init = ransac_global(a, b, fpfh_a, fpfh_b)
    T, rmse = icp_multiscale(b, a, T_init, cfg['icp_max_iter'], cfg['icp_tolerance_mm'])
    return T, rmse

第 18 章 M5 质检算法
18.1 覆盖率与重叠度
覆盖率 = 被有效点云/纹理覆盖的模型表面积占比；重叠度 = 多视角纹理重叠比例。二者低于阈值则标记
不达标。
18.2 特征点中误差
在模型上布设/选取特征点，与参照（靶标或已知坐标）比较，计算中误差。精细级目标 ≤ 5 mm（以用户
验收细则为准）。
def qc_rmse(model_pts, ref_pts):
    d = np.linalg.norm(model_pts - ref_pts, axis=1)
    return float(np.sqrt(np.mean(d**2)))  # 单位: mm

class Worker(QThread):
    progress = Signal(int, int)   # 当前, 总数
    log = Signal(str)
    finished = Signal(dict)
    def run(self):
        # 调用编排内核(与 CLI 同一份代码)
        for i, item in enumerate(items):
            result = orchestrate(item, cfg)
            self.progress.emit(i+1, len(items))
        self.finished.emit(summary)
# 主线程
worker = Worker(); worker.progress.connect(bar.setValue)
worker.log.connect(log_edit.append); worker.start()

第 27 章 性能与可靠性

• 可靠性：断点续跑使中断后可恢复；失败隔离保证单尊失败不波及全队列。

27.1 可靠性设计要点
• 幂等：重复运行同一阶段不产生副作用。
• 原子写：中间产物写完再更新 manifest 指针。
• 隔离：单尊异常被捕获并记入 manifest，不抛出至队列层。

31.2 处理流程
def orchestrate(item, cfg, manifest):
    for stage in ['M1','M2','M3','M4','M5','M6']:
        if manifest.stages.get(stage, {}).get('status') == 'done':
            continue  # 断点续跑: 已完成则跳过
        fn = MODULES[stage]
        try:
            res = fn(item, cfg)
            manifest.record(stage, res)   # 先记 manifest 再落盘
        except RecoverableError as e:
            manifest.record_fail(stage, str(e))
            log.warning('skip %s: %s', item, e)
            break  # 失败隔离: 该尊中止, 不抛到队列
    return manifest.summary()

第 44 章 关键算法数学表述
44.1 精配准（ICP，point-to-plane）
目标：寻找变换 T 使源点云 Y 与目标点云 X 对齐。point-to-plane 最小化点到目标面切平面的距离平方和
：
min_T  sum_i  | (R*y_i + t - x_i) . n_i |^2
其中 n_i 为 x_i 处法向, R 为旋转, t 为平移。
多尺度: 由粗到细逐级缩小容差 tolerance，直至收敛或达 icp_max_iter。
44.2 泊松表面重建
将定向点云视为隐函数 f 的梯度场，通过求解泊松方程 Δf =  ·V 重建等值面；depth 控制八叉树细分深度
，决定细节层级与内存开销。
44.3 M3C2 距离（多时相变化）
对 core point p (半径 r 内):
  d(p) = proj_dist( 拟合面1(p,r), 拟合面2(p,r) )
变化显著区: |d(p)| > change_mm 且超过局部不确定性。
44.4 CIEDE2000 色差
CIEDE2000 在 CIELAB 基础上引入亮度、彩度、色调权重与交互项，较 ΔE76 更贴合人眼感知；本系统用
于量化纹理与实采色卡的色彩保真差异，阈值依文物色彩管理要求设定。
delta_E_00 = f(L1,a1,b1, L2,a2,b2)   # 含旋转项与补偿项
判定: mean(delta_E_00) <= color_tolerance 视为色彩保真达标

附录 C 常见错误与排查（20 条）
1. E100 输入缺失：检查 00_raw 下文件是否存在且未损坏。
2. E200 配准失败：确认站点间有重叠区域，尝试放宽粗配准半径。
3. E500 质检不达标：覆盖不足→补扫；中误差大→检查靶标与参考。
4. 模块中断：查看 90meta/runmanifest.json 的 status，从失败阶段重跑。
5. 内存溢出：降低下采样目标分辨率或分块处理。
6. 纹理拉伸：提高 UV 展开质量或重参数化高拉伸区域。
7. 导出无法打开：确认导出格式与目标软件兼容（优先 glb/obj）。
8. GUI 卡顿：确认耗时计算在 Worker 线程，不在主线程。
9. 进度不刷新：检查信号槽连接是否正确。
10. 许可证告警：核查是否误引入 GPL 库，移除或改为子进程。
11. 配置不生效：确认 config.yaml 路径与字段名，查看启动日志。
12. 坐标系异常：执行坐标归一化与朝向校正（M1）。
13. 闭环误差大：增加约束或人工指定初始对齐。
